## 為什麼需要一條格式列

如果你已經會寫 Markdown，Obsidian 就很快。但對其他人——學生、從 Word 或 Google Docs 轉過來的寫作者、正在帶新人的團隊——語法本身就是一堵牆。

- **不必背語法。** 選取文字，按**粗體**，就這樣。
- **你本來就認識的 Word 用語。** 常用 / 插入 / 檢視 / 表格選項卡、「清除所有格式」、「變更大小寫」、「導覽窗格」。
- **發掘 Obsidian 本來就有的能力。** 標註、區塊參照、內嵌、公式區塊、標籤全都有按鈕——很多使用者從來沒在語法裡發現過它們。
- **做 Markdown 做不到的事。** 底線、上標、下標、段落對齊、文字與醒目提示色彩、字型與字型大小，以乾淨的行內 HTML 寫入。
- **永遠是純文字。** 沒有專屬格式、沒有資料庫、沒有綁定——你的筆記仍然只是 `.md` 檔案。
- **離線且私密。** 不連網路、不要帳號、無遙測，約 2,150 筆的表情符號庫直接包在外掛裡。
- **想要自己的啟動器，也給你。** 「已釘選」選項卡放得下你挑的任意指令——核心指令、本外掛的、或其他外掛的——工具列於是你說了算，而不必變成一個設定工程。
- **也照顧鍵盤派。** 把三處工具列位置全部關掉，介面就徹底消失——144 筆已註冊到命令面板的指令依然可用，可以綁成你自己的快捷鍵。而當工具列**開著**的時候，滑鼠懸停按鈕會在提示中顯示該指令目前綁定的快捷鍵——你指定的，或 Obsidian 內建的預設鍵。在**設定 → 快捷鍵**中重新綁定，提示會立刻跟著變，不必重新啟動。

## 功能

### 🧭 三處工具列位置，自由組合

- **功能區（頂端）** —— 固定在編輯器上方的完整分頁工具列。*預設。*
- **跟隨** —— 浮在目前選取範圍上方的精簡工具列，類似 Word 或 Google Docs 的選取工具列。 **跟隨列永遠不會蓋住你正在編輯的內容。**
- **底部** —— 固定在編輯器底部的精簡工具列。

每個位置各自獨立開關，你可以只用跟隨列、只用功能區，或者三處全開。

### 🅰️ 159 筆排版指令，版面配置你熟悉

粗體、斜體、底線、刪除線、行內程式碼、行內公式、醒目提示（可選色彩）、字型色彩、**字型**、**字型大小**、清除所有格式、變更大小寫、標題 1–6、項目符號 / 編號 / 工作清單、引文、縮排、分隔線、復原 / 重複、尋找及取代、段落對齊——全都依照 Word 使用者預期的位置分組。

圖片在**插入**選項卡上有自己的分組：**圖片大小 ▼**可設定 100–600 像素的寬度——或還原檔案本身的尺寸——**所有圖片 ▼**一次把同一個寬度套用到筆記裡的每一張圖片，**替代文字**寫入替代文字並選取它，**題註**則在圖片下方寫入一行題註並選取它，可以直接輸入覆寫。**重設圖片**再把寬度和替代文字移除，**轉換語法**則在 `![[a.png]]` 與 `![](a.png)` 之間來回切換。

### 💬 標註選擇器 —— 12 種類型全包

一個**標註**按鈕開啟下拉選單，內含 `note`、`abstract`、`info`、`tip`、`success`、`question`、`warning`、`failure`、`danger`、`bug`、`example`、`quote`。不必再查 `> [!tip]` 怎麼寫。

### 😀 離線表情符號、顏文字與符號選擇器（約 2,150 筆）

可搜尋的**表情符號與符號**面板，三個來源——表情符號、顏文字、排版符號——隨外掛一起打包。在游標處插入或覆蓋選取範圍，只產生一個復原步驟，每個來源各自保留「常用」分組，並且保持開啟以便連續插入多個字元。

### 📊 Markdown 表格編輯器

插入 / 刪除列欄、移動列欄、欄靠左 / 置中 / 靠右對齊、列由 A 到 Z 或由 Z 到 A 排序、刪除重複列、轉置表格、重排格式（美化）目前的表格或筆記中的每一個表格、把表格轉回以分隔符號分隔的文字——外加**貼上為表格**：把剪貼簿中以 Tab 或逗號分隔的文字（直接從 Excel、Numbers 或 Google 試算表複製出來的）變成對齊好的 Markdown 表格，以及**複製為 ▼**，可以輸出成 TSV、CSV、JSON 或 Markdown 走回試算表。

把游標放進表格裡，功能區就會自己切到**表格**選項卡；你改選別的選項卡，它就停在你選的那個。**原始碼模式**下，Enter 移到下一列（到最後一列時新增一列），Tab / Shift+Tab 則逐格移動，超過右側邊緣時新增一欄。

### 📌 釘選任何指令 —— 包含其他外掛的指令

**「已釘選」是工具列裡唯一由你自己安排的部分。**它把工具列變成你自己的啟動器：從命令面板挑任何指令（Obsidian 核心、其他社群外掛、或本外掛的），選一個圖示，給它一個分組，拖曳排序。如果來源外掛被停用，按鈕只是變灰——你的釘選會保留。

五個內建選項卡涵蓋了多數人常用的指令；而你真正離不開的那一兩個指令，往往落在這套之外——所以與其讓你重建五個選項卡去夠到它們，工具列乾脆給你第六個、完全屬於你的，而且更新時永不覆寫。

### 👁️ 閱讀、專注與大綱工具

**即時預覽/原始碼**（把窗格在轉譯後與原始 Markdown 之間切換）、**顯示空格**（空格顯示點、定位字元顯示箭頭、不換行空格 / 表意空格 / EN & EM 空格顯示橘色標記）、**顯示行號**、**可讀行寬**、**導覽窗格**（Obsidian 的大綱）、**放大 / 縮小 / 100%**、**向右 / 向下分割**、**摺疊 / 展開（全部）**、**專注模式**（收起兩側邊欄）、**禪模式**（真正的全螢幕）與**打字機模式**（游標行固定在編輯器中間並強調，其餘行淡化）。

### 📑 一鍵產生目錄

**目錄**會在游標所在段落之後寫入目前筆記的大綱：一個粗體的 `**目錄**` 標題，然後每個標題一列巢狀的 `- [[#標題|標題]]` 連結。程式碼圍欄內或被引用進標註裡的標題會被忽略。它是快照，不是即時欄位——改完筆記請重新執行，並刪掉舊的。

### 🧹 行與清單工具

**合併列**、**分割列**（依選取範圍中出現最多的標點符號切開）、**反轉行**——三者都不會跨越空白行或程式碼圍欄——還有**重複**（在游標所在列下方複製一份，或在選取範圍之後緊接著複製一份——VS Code 的 *Duplicate Selection*），以及**排序清單**（逐層排序，保留子項目與本文，編號項目重新編號）與**排序標題**（重排大綱，並把每個章節的本文一起帶著走）。

**清理**把大家平時得手動做的整理一次收進同一個選單：**移除行尾空白**、**合併連續空白行**、**轉換裸 URL**、**統一強調與粗體**與**統一項目符號樣式**。

### 🎨 零設定，跟隨主題

內建版面是固定的，在淺色與深色模式下都繼承你目前使用的 Obsidian 主題，裝上時就像原生的一樣，並且一直如此。唯一需要你安排的，是**已釘選**選項卡。

這是刻意的取捨，不是缺失的功能。一個容許你重建每一個按鈕的工具列，還得額外揹上一套拖曳編輯器、一個圖示瀏覽器、一種匯入匯出格式，以及一個裝下這一切的設定頁——而工具列的 bug 恰恰就出自這套機械結構：按鈕拖不動、版面被更新重置、設定面板卡死。固定版面一樣都沒有。你得到的是裝上就能用、並且一直好用的工具列，而那些真正屬於你的指令，出口就是**已釘選**。

## 完整命令參考

159 筆指令中有 144 筆註冊進了**命令面板**，可以為它們指定自己的快捷鍵。（下拉容器與表情符號與符號面板只出現在工具列。）

### 常用

- **剪貼簿** —— 貼上、剪下、複製、貼上為純文字
- **字型** —— 字型、字型大小、粗體、斜體、底線、刪除線、下標、上標、行內程式碼、行內公式、醒目提示、醒目提示色彩、字型色彩、清除所有格式、變更大小寫
- **段落** —— 項目符號 / 編號 / 工作清單、 **編號標題 ▼** (1. 1.1. 1.1.1., 1) a) i), I. A. 1., 無編號)、引文、減少 / 增加縮排、重新編號、段落排序、上移清單項目 / 下移清單項目、上移一列 / 下移一列、靠左對齊 / 置中 / 靠右對齊 / 左右對齊、分隔線
- **樣式** —— 標題 1–6、轉為本文
- **編輯** —— 復原、重複、尋找及取代

### 插入

- **連結** —— 內部連結、外部連結、內嵌、標籤、區塊參照
- **區塊** —— 標註 ▼（註解標註、摘要標註、資訊標註、提示標註、成功標註、問題標註、警告標註、失敗標註、危險標註、缺陷標註、範例標註、引文標註）、程式碼區塊、公式區塊、表格、文字轉換為表格、註解
- **圖片** —— 圖片大小 ▼（100 像素、200 像素、300 像素、400 像素、600 像素、原始大小）、所有圖片 ▼（所有圖片 100 像素、所有圖片 200 像素、所有圖片 300 像素、所有圖片 400 像素、所有圖片 600 像素、所有圖片 原始大小）、替代文字、題註、重設圖片、轉換語法
- **媒體與符號** —— 附加檔案、表情符號與符號、日期與時間
- **參照** —— 目錄、腳注

### 檢視

- **檢視** —— 即時預覽/原始碼（把窗格在即時預覽與原始 Markdown 之間切換）
- **沉浸式** —— 專注模式、禪模式、打字機模式
- **顯示** —— 顯示空格、顯示行號、可讀行寬、導覽窗格（Obsidian 的大綱）
- **縮放** —— 放大、縮小、100%
- **視窗** —— 向右分割、向下分割
- **大綱** —— 摺疊、展開、全部摺疊、全部展開

### 表格

游標位於表格內時可用：

- **列與欄** —— 刪除列或欄 ▼（刪除列、刪除欄）、在上方 / 下方插入列、在左側 / 右側插入欄、列上移 / 列下移、欄左移 / 欄右移
- **格式** —— 格式化表格 ▼（格式化此表格、格式化所有表格）
- **對齊方式** —— 欄靠左 / 置中 / 靠右對齊
- **資料** —— 列排序 ▼（由 A 到 Z 排序、由 Z 到 A 排序）、刪除重複列、轉置表格、將表格轉換為文字
- **剪貼簿** —— 貼上為表格、複製為 ▼（TSV / CSV / JSON / Markdown）

### 公用工具

- **行** —— 合併列、分割列、反轉行、重複。**合併列**把連續多列併成一列；**分割列**依選取範圍中出現最多的標點符號切開；**反轉行**把每組列的順序倒過來；**重複**把游標所在的列複製到它下方，或把選取範圍複製到它後面。四者都不會跨越空白行或程式碼圍欄。
- **排序** —— 排序清單、排序標題。**排序清單**逐層排序——每個項目保留自己的本文與子項目，編號項目輸出時重新編號。**排序標題**重排筆記大綱的每一層，並把每個章節的本文一起帶著走。
- **連結** —— 貼上 URI 為連結，會用剪貼簿中的 URI 將選取文字包成連結。
- **正規化** —— 智慧標點、中日韓間距、清理 ▼（移除行尾空白、合併連續空白行、轉換裸 URL、統一強調與粗體、統一項目符號樣式）。

## 快速上手

1. 開啟**設定 → Awesome Format Bar**，勾選你想要的位置：**頂端**、**跟隨**、**底部**。
2. **功能區（頂端）**有六個選項卡；最後一個**已釘選**放你自己釘選的指令。在它還是空的時候會顯示一則邀請你新增指令的提示；用編輯按鈕來管理指令與分組。
3. **精簡工具列**（跟隨 / 底部）只帶固定的一部分指令，放不進可用寬度的按鈕會收進 `⋯` 溢位選單，這個選單同時也按選項卡分組列出所有其他指令，以及你釘選的指令。
4. 開啟**已釘選**的編輯按鈕，即可新增指令、選擇圖示、新增分組…或重新命名分組、拖曳重新排序、將指令移至其他分組，或將它們刪除。設定中也保留了一個備用入口，開啟的是同一個管理器（管理已釘選的命令和分組）。已釘選的指令，行為與它在命令面板中的對應指令完全相同。
5. 更偏好鍵盤？把**三個位置開關全部關掉**，工具列就從介面中徹底消失——外掛在畫面上不留任何東西，而 **144 筆已註冊至命令面板的指令**依然可用，你可以在**設定 → 快捷鍵**中為它們綁定自己的快捷鍵。換句話說：你可以只把它當成一個純指令 / 快捷鍵包，一個按鈕都不點。

## 常見問題

**這會把 Obsidian 變成所見即所得或富文字編輯器嗎？**  
不會——這正是重點。它是疊在 Obsidian 自有編輯器之上的**工具列**，你的檔案仍然是純 Markdown。

**現在用 Obsidian 還得先學 Markdown 語法嗎？**  
不用。粗體、標題、清單、連結、表格、標註、程式碼區塊與公式全都是按鈕。

**到底會往我的筆記裡寫什麼？**  
標準 Markdown 與 Obsidian 風味 Markdown。只有在 Markdown 沒有語法的地方——底線、上標、下標、段落對齊、文字與醒目提示色彩、字型與字型大小——外掛才會寫入少量標準行內 HTML 標籤，Obsidian 原生即可轉譯。

**我還能繼續用快捷鍵嗎？**  
能。159 筆指令中有 144 筆出現在命令面板，可以綁定到任何快捷鍵。

**我是鍵盤派——能把工具列完全藏起來嗎？**  
能，而且這樣做什麼都不會少。在**設定 → Awesome Format Bar** 中把三處位置（**頂端 / 跟隨 / 底部**）全部關掉，外掛在畫面上零痕跡：沒有功能區、沒有浮動列、沒有底列。**144 筆已註冊指令**依然全部能跑，從命令面板執行，或從你在**設定 → 快捷鍵**中指定的快捷鍵執行——包括那些 Obsidian 沒有內建快捷鍵的指令，例如字型色彩、醒目提示色彩、變更大小寫、標註、表格排序與列處理工具。把它當成一個隨時可開的純鍵盤層即可，等滑鼠慢下來時再想起它。

**我能為其他外掛的指令新增按鈕嗎？**  
能——就是**已釘選**選項卡。從命令面板釘選任何指令並選一個圖示。如果來源外掛被停用，按鈕變灰，釘選保留。

**表情符號選擇器需要連上網路嗎？**  
不需要。約 2,150 筆表情符號、顏文字與符號全部隨外掛打包。

**這個外掛會用到 AI，或以任何方式回傳資料嗎？**  
不會。程式碼裡沒有任何 AI 功能、沒有 API 金鑰、沒有網路請求、沒有分析、也沒有遙測——外掛只讀寫你本機的 `.md` 檔案，除此之外什麼都不做。表情符號庫隨外掛打包，所以就算在飛機上也照樣能用。

**在閱讀模式中替表格排序會改動我的檔案嗎？**  
不會。閱讀模式下按一下標題排序只是顯示層面，絕不修改筆記。

**要怎麼把圖片置中，或調整它的大小？**  
把游標放在圖片所在的那一列。**置中**（常用 · 段落）就能將它置中——單獨佔一列的圖片*就是*一個段落，所以不需要另外的指令——而**圖片大小 ▼**（插入 · 圖片）可將寬度設為 100–600 像素，或用**原始大小**還原檔案本身的尺寸；寬度寫在別名之後而不是覆蓋它，所以 `![[logo.png|公司標誌]]` 會變成 `![[logo.png|公司標誌|300]]`。**所有圖片 ▼**不論游標在筆記何處，都一次把同一個寬度套用到每一張圖片。**替代文字**寫入替代文字並選取它，**題註**在下方寫入一行題註並選取它，而**重設圖片**把這兩者都移除。**轉換語法**在 `![[a.png]]` 與 `![](a.png)` 之間來回切換。一切都以純 Obsidian 語法寫入，所以就算沒有這個外掛，筆記讀起來也一模一樣。

**想要乾淨畫面時能把工具列藏起來嗎？**  
能——在設定中關掉任一位置，或三個全關徹底隱藏（關掉後還剩什麼可用，見上面那則鍵盤問題）。

**它可以設定嗎？**  
刻意做得很少——而這正是重點。內建版面固定且跟隨主題，所以看起來永遠像原生，永遠不需要重新排列，也永遠不會被更新重置。你真正想改的東西全在一處：**已釘選**選項卡——在這裡新增任何指令、挑圖示、分組、拖曳成你要的順序。理由見*功能 → 零設定，跟隨主題*。

## 開發

```shell
npm install        # 安裝相依套件
npm run build      # 型別檢查 + 測試 + 生產建置
npm run deploy -- /path/to/vault   # 把 main.js、manifest.json、styles.css 複製進保存庫
```

發布物只有三個檔案：`main.js`、`manifest.json`、`styles.css`。

---

## 發布

```shell
npm version patch                    # 遞增 package.json、manifest.json、versions.json；提交並建立標籤
git push origin main --follow-tags   # 推送提交與標籤
```

`npm version` 要求工作區乾淨。標籤不帶 `v` 前置詞——它必須等於 `manifest.json` 中的 `version`，否則發布工作流程會拒絕。

推送標籤會觸發 `.github/workflows/release.yml`：建置外掛，並建立一個附上 `main.js`、`manifest.json`、`styles.css` 的**草稿**發布。發布這份草稿，該版本就對外可用了。
