## 为什么需要一条格式栏

如果你已经会说 Markdown，Obsidian 就很快。可对其他人——学生、从 Word 或 Google Docs 转过来的写作者、正在带新人的团队——语法本身就是一堵墙。

- **不用背语法。** 选中文字，点**加粗**，完事。
- **你本来就认识的 Word 术语。** 开始 / 插入 / 视图 / 表格 选项卡，"清除格式"、"更改大小写"、"导航窗格"。
- **发现 Obsidian 本就有的能力。** Callout、块引用、嵌入、数学块、标签全都有按钮——很多用户从来没在语法里发现过它们。
- **做 Markdown 做不到的事。** 下划线、上标、下标、段落对齐、文字与高亮颜色、字体和字号，以干净的行内 HTML 写入。
- **永远是纯文本。** 没有私有格式、没有数据库、没有锁定——你的笔记仍然只是 `.md` 文件。
- **离线且私密。** 不联网、不要账号、无遥测，约 2,150 条表情库直接打进插件里。
- **也照顾键盘党。** 把三处工具栏位置全部关掉，界面彻底消失——105 条已注册到命令面板的命令依然可用，可绑定成你自己的快捷键。

## 功能

### 🧭 三处工具栏位置，自由组合

- **功能区（顶部）** —— 固定在编辑器上方的完整分页工具栏。*默认开启。*
- **跟随** —— 浮在当前选区上方的精简工具栏，类似 Word 或 Google Docs 的选中工具条。
- **固定** —— 钉在编辑器底部的精简工具栏。

每处位置独立开关，你可以只用跟随栏、只用功能区，或者三处全开。

### 🅰️ 115 条排版命令，布局你熟悉

加粗、斜体、下划线、删除线、行内代码、行内公式、高亮（可选颜色）、字体颜色、**字体**、**字号**、清除格式、更改大小写、标题 1–6、无序 / 有序 / 任务列表、引用、缩进、分割线、撤销 / 重做、查找替换、段落对齐——全都按 Word 用户预期的位置分组。

### 💬 Callout 选择器 —— 12 种类型全包

一个 **Callout** 按钮打开下拉列表，包含 `note`、`abstract`、`info`、`tip`、`success`、`question`、`warning`、`failure`、`danger`、`bug`、`example`、`quote`。不用再查 `> [!tip]` 怎么写了。

### 😀 离线表情、颜文字与符号选择器（约 2,150 条）

可搜索的**表情与符号**面板，三个来源——表情、颜文字、排版符号——随插件一起打包。在光标处插入或覆盖选区，只产生一次撤销步骤，每个来源各自保留「常用」分组，并且保持打开以便连续插入多个字符。

### 📊 Markdown 表格编辑器

插入 / 删除行列、移动行列、列左中右对齐、行排序、重排格式（美化表格）——外加**粘贴为表格**：把剪贴板里以制表符或逗号分隔的文本（直接从 Excel、Numbers 或 Google Sheets 复制的）变成对齐好的 Markdown 表格。

### 📌 固定任意命令 —— 包括其他插件的命令

**已固定**选项卡把工具栏变成你自己的启动器：从命令面板里挑任意命令（Obsidian 核心、其他社区插件、或本插件的），选一个图标，拖动排序。如果来源插件被禁用，按钮只是变灰——你的固定项会保留。

### 👁️ 阅读、专注与大纲工具

**显示空白字符**（空格显示点、制表符显示箭头、不换行空格 / 表意空格 / EN & EM 空格显示橙色标记）、**显示行号**、**可读行宽**、**导航窗格**（Obsidian 的大纲）、**放大 / 缩小 / 100%**、**向右 / 向下拆分**、**折叠 / 展开（全部）**、**专注模式**（收起两侧边栏）、**禅模式**（真正全屏）和**打字机模式**（光标行固定在编辑器中部并高亮，其余行淡化）。

### 📑 一键生成目录

**目录**会在光标所在段落之后写入当前笔记的大纲：一个加粗的 `**目录**` 标题，然后每个标题一行嵌套的 `- [[#标题|标题]]` 链接。代码块内或被引用进 Callout 的标题会被忽略。它是快照，不是实时字段——改完笔记请重新生成，并删掉旧的。

### 🧹 行与列表工具

**合并行**、**拆分行**（按选区中出现最多的标点拆开）、**反转行**——三者都不会跨越空行或代码块——以及**排序列表**（逐层排序，保留子项与正文，有序列表重新编号）和**排序标题**（重排大纲，并把每个章节的正文一起搬走）。

### 🎨 零配置，跟随主题

固定、克制的布局，在浅色与深色模式下都继承你当前使用的 Obsidian 主题。唯一需要你自行安排的，是「已固定」选项卡。

## 完整命令参考

115 条命令中有 105 条注册进了**命令面板**，可以给它们指定自己的快捷键。（下拉容器与表情符号面板只在工具栏中出现。）

### 开始

- **剪贴板** —— 粘贴、剪切、复制、粘贴为纯文本
- **字体** —— 字体、字号、加粗、斜体、下划线、删除线、下标、上标、行内代码、行内公式、高亮、高亮颜色、字体颜色、清除格式、更改大小写
- **段落** —— 无序 / 有序 / 任务列表、引用、减少 / 增加缩进、重新编号列表、排序行、上移 / 下移行、左 / 中 / 右 / 两端对齐、分割线
- **样式** —— 标题 1–6、移除标题
- **编辑** —— 撤销、重做、查找和替换

### 插入

内部链接、外部链接、嵌入、标签、块引用、**Callout ▼**（Note、Abstract、Info、Tip、Success、Question、Warning、Failure、Danger、Bug、Example、Quote）、代码块、数学块、表格、文本转换为表格、注释、附件、**表情与符号**、日期与时间、**目录**、脚注。

### 视图

- **显示** —— 显示空白字符、显示行号、可读行宽、导航窗格（Obsidian 大纲）
- **缩放** —— 放大、缩小、100%
- **窗口** —— 向右拆分、向下拆分
- **大纲** —— 折叠、展开、全部折叠、全部展开
- **沉浸** —— 专注模式、禅模式、打字机模式

### 表格

光标位于表格内时可用：删除行 / 列、在上方 / 下方插入行、在左侧 / 右侧插入列、上移 / 下移行、左移 / 右移列、格式化表格、列左 / 中 / 右对齐、行排序、**转换为文本**。  
**转换为文本**把表格写成制表符分隔的行——正好是**文本转换为表格**（插入 · 区块）的逆操作，后者把制表符或逗号分隔的文本变成对齐的 Markdown 表格。**粘贴为表格**对剪贴板做同样的事，且在任何位置都能用。

### 工具

**合并行**把连续多行拼成一行；**拆分行**按选区中出现最多的标点断开；**反转行**把每组行的顺序倒过来。三者都不会跨越空行或代码块。  
**排序列表**逐层排序——每一项保留自己的正文与子项，有序项输出时重新编号。**排序标题**重排笔记大纲的每一层，并把每个章节的正文一起带着走。
**粘贴 URI 为链接**会用剪贴板中的 URI 将选中文本包裹成链接。**智能标点**和**中日韩间距**会规范化选中文本，**清理**则把常见的 Markdown 清理操作集中到一个菜单中。

### 已固定

你自己的命令，配你自己的图标。参见[快速上手](#快速上手)。

### 表情与符号面板

| 来源  | 条数（约）  | 示例分组                    |
| --- | ------ | ----------------------- |
| 表情  | ~1,900 | 笑脸与人物、动物与自然、食物与饮品、物品、旗帜 |
| 颜文字 | ~70    | 情绪、动物、行为、人物、节日          |
| 符号  | ~200   | 箭头、数学、排版、货币、带圈字符、装饰符号   |

所有数据都随插件打包，选择器完全离线可用。

## 安装

需要 Obsidian **1.13.7 或更高版本**。

**从社区插件市场安装（推荐）**  
设置 → **第三方插件** → **浏览** → 搜索 **“Awesome Format Bar”** → **安装** → **启用**。

**用 BRAT 安装（测试版）**  
安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat)，执行 *BRAT: Add a beta plugin*，粘贴本仓库地址。

**手动安装**  
从发布页下载 `main.js`、`manifest.json`、`styles.css` 三个文件，放进 `<库路径>/.obsidian/plugins/awesome-format-bar/`，然后在设置 → 第三方插件中启用。

## 快速上手

1. 打开**设置 → Awesome Format Bar**，勾选你想要的位置：**顶部**、**跟随**、**固定**。
2. **功能区（顶部）**&#x6709;六个选项卡；最后一个**已固定**放你自己固定的命令。它为空时会显示一条指回设置的提示。
3. **精简工具栏**（跟随 / 固定）只放固定的一部分命令，放不下的会收进 `⋯` 溢出菜单。
4. 在**设置 → 已固定**里固定命令：添加（先选命令，再选图标）、改图标、拖动排序、删除。固定后的命令行为与命令面板里的一模一样。
5. 更爱用键盘？把**三个位置开关全部关掉**，工具栏就从界面里彻底消失——插件不在屏幕上留下任何东西，而 **105 条已注册命令**依然可用，你可以在**设置 → 快捷键**里给它们绑定自己的热键。换句话说：你可以只把它当成一个纯命令 / 快捷键包，一个按钮都不点。

## 常见问题

**这会把 Obsidian 变成所见即所得或富文本编辑器吗？**  
不会——这正是重点。它是叠在 Obsidian 自有编辑器之上的**工具栏**，你的文件仍然是纯 Markdown。

**现在用 Obsidian 还得先学 Markdown 语法吗？**  
不用。加粗、标题、列表、链接、表格、Callout、代码块和公式全都是按钮。

**到底会往我的笔记里写什么？**  
标准 Markdown 和 Obsidian 风味 Markdown。只有在 Markdown 没有语法的地方——下划线、上标、下标、段落对齐、文字与高亮颜色、字体与字号——插件才会写入少量标准行内 HTML 标签，Obsidian 原生即可渲染。

**我还能继续用快捷键吗？**  
能。115 条命令中有 105 条出现在命令面板里，可以绑定到任意热键。

**我是键盘党——能把工具栏完全藏起来吗？**  
能，而且这样做什么都不会丢。在**设置 → Awesome Format Bar**里把三处位置（**顶部 / 跟随 / 固定**）全部关掉，插件在屏幕上零痕迹：没有功能区、没有浮动栏、没有底栏。**105 条已注册命令**依然全部可跑，从命令面板走，或者从你在**设置 → 快捷键**里指定的热键走——包括那些 Obsidian 没有内置快捷键的命令，比如字体颜色、高亮颜色、更改大小写、Callout、表格排序和行处理工具。把它当成一个随时可开的纯键盘层就行，鼠标慢的时候再想起来。

**我能给其他插件的命令加按钮吗？**  
能——就是**已固定**选项卡。从命令面板固定任意命令并选一个图标。如果来源插件被禁用，按钮变灰，固定项保留。

**表情选择器需要联网吗？**  
不需要。约 2,150 条表情、颜文字与符号全部随插件打包。

**在阅读视图里给表格排序会改动我的文件吗？**  
不会。阅读视图下点击表头排序只是显示层面的，绝不修改笔记。

**想要干净屏幕时能把工具栏藏起来吗？**  
能——在设置里关掉任意位置，或者三个全关彻底隐藏（上面那条键盘问题里说明了关掉后还剩什么可用）。

**它可配置吗？**  
刻意做得很少：布局固定且跟随主题，所以看起来永远是原生的。「已固定」选项卡交给你自己安排。

## 开发

```shell
npm install        # 安装依赖
npm run dev        # 监听模式构建
npm run build      # 类型检查 + 测试 + 生产构建
npm run test       # 运行单元测试
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
npm run deploy -- /path/to/vault   # 把 main.js、manifest.json、styles.css 复制进笔记库
```

发布物只有三个文件：`main.js`、`manifest.json`、`styles.css`。

## 发布

```shell
npm version patch                    # 递增 package.json、manifest.json、versions.json；提交并打 tag
git push origin main --follow-tags   # 推送提交与标签
```

`npm version` 要求工作区干净。标签不带 `v` 前缀——它必须等于 `manifest.json` 里的 `version`，否则发布工作流会拒绝。

推送标签会触发 `.github/workflows/release.yml`：构建插件，并创建一个附带 `main.js`、`manifest.json`、`styles.css` 的**草稿**发布。发布这个草稿，该版本就对外可用了。
