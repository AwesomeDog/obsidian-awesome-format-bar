What it does — and doesn't

Clicking cycles ascending → descending → original. Only the rendered rows reorder — the file on disk is never modified, and the state resets whenever the note is re-rendered.

Two faint carets sit on every header so the feature is discoverable; the sorted column shows the live direction. Turn the setting off and the arrows disappear with the behavior.

Paste as Table

Tab- or comma-separated clipboard text becomes an aligned Markdown table at the cursor. An explicit command — regular Paste is untouched, and this one stays enabled even outside a table.

Context aware

The whole tab is disabled when the cursor isn't inside a table, so you never wonder which button applies to what.

Editing behavior

Enter moves to the next row and cells pad with spaces — both on by default, both under Settings → Table.

Insert · Media & Symbols

One search box over the active source, matching an entry's name and keywords. Each source keeps its own Frequently used group — per source, not global, so kaomoji never get crowded out by emoji.

Pick several in a row

The panel stays open after each insert, then closes on Escape or an outside click and returns focus to the editor.

One undo step

Each entry inserts over the selection or at the caret as a single undo step, with the default skin tone. Raw Unicode — no :shortcodes:, no autocomplete.

Available everywhere

Wherever the editor is in source mode, in every position including the Compact overflow menu. It isn't in the command palette — its only job is to open the panel.

Settings

Four sections.
That's the whole thing.

Toolbar

Independent toggles for Top, Following and Fixed. Defaults to Top; turning every position off keeps it off.

Pinned

Add a command, choose a Lucide icon, drag to reorder, delete. Pinning is one-time, low-frequency setup — so it lives here, not on the toolbar, where a + would eat scarce horizontal space.

Table

Enter moves to the next row. Pad cell width with spaces. Sort by clicking a header in Reading view. All on by default; all about editing behavior and text output, never toolbar layout.
