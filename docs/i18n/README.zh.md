## 为什么需要一条格式栏

如果你已经会说 Markdown，Obsidian 就很快。可对其他人——学生、从 Word 或 Google Docs 转过来的写作者、正在带新人的团队——语法本身就是一堵墙。

- **不用背语法。** 选中文字，点**加粗**，完事。
- **你本来就认识的 Word 术语。** 开始 / 插入 / 视图 / 表格 选项卡，"清除格式"、"更改大小写"、"导航窗格"。
- **发现 Obsidian 本就有的能力。** Callout、块引用、嵌入、数学块、标签全都有按钮——很多用户从来没在语法里发现过它们。
- **做 Markdown 做不到的事。** 下划线、上标、下标、段落对齐、文字与高亮颜色、字体和字号，以干净的行内 HTML 写入。
- **永远是纯文本。** 没有私有格式、没有数据库、没有锁定——你的笔记仍然只是 `.md` 文件。
- **离线且私密。** 不联网、不要账号、无遥测，约 2,150 条表情库直接打进插件里。
- **想要自己的启动器，也给你。** 「已固定」选项卡放得下你挑的任意命令——核心命令、本插件的、或其他插件的——工具栏于是为你而变，却不必变成一个配置工程。
- **也照顾键盘党。** 把三处工具栏位置全部关掉，界面彻底消失——144 条已注册到命令面板的命令依然可用，可绑定成你自己的快捷键。而当工具栏**开着**的时候，鼠标悬停按钮会在提示里显示该命令当前绑定的快捷键——你指定的，或 Obsidian 自带的默认键。在**设置 → 快捷键**里改绑，提示会立刻跟着变，不用重启。

## 功能

### 🧭 三处工具栏位置，自由组合

- **功能区（顶部）** —— 固定在编辑器上方的完整分页工具栏。*默认开启。*
- **跟随** —— 浮在当前选区上方的精简工具栏，类似 Word 或 Google Docs 的选中工具条。**跟随条永远不会遮住你正在编辑的内容。**
- **固定** —— 钉在编辑器底部的精简工具栏。

每处位置独立开关，你可以只用跟随栏、只用功能区，或者三处全开。

### 🅰️ 159 条排版命令，布局你熟悉

加粗、斜体、下划线、删除线、行内代码、行内公式、高亮（可选颜色）、字体颜色、**字体**、**字号**、清除格式、更改大小写、标题 1–6、无序 / 有序 / 任务列表、引用、缩进、分割线、撤销 / 重做、查找替换、段落对齐——全都按 Word 用户预期的位置分组。

图片在**插入**选项卡上有自己的分组：**图片大小 ▼**可把宽度设为 100–600 像素，或恢复文件本身的尺寸；**所有图片 ▼**一次性把同一宽度应用到笔记里的每一张图片，**替代文本**写入替代文本并选中它，**题注**则在图片下方写入一行题注并选中它，直接输入就能覆盖。**重置图片**再把宽度和替代文本去掉，**转换语法**则在 `![[a.png]]` 与 `![](a.png)` 之间来回切换。

### 💬 Callout 选择器 —— 12 种类型全包

一个 **Callout** 按钮打开下拉列表，包含 `note`、`abstract`、`info`、`tip`、`success`、`question`、`warning`、`failure`、`danger`、`bug`、`example`、`quote`。不用再查 `> [!tip]` 怎么写了。

### 😀 离线表情、颜文字与符号选择器（约 2,150 条）

可搜索的**表情与符号**面板，三个来源——表情、颜文字、排版符号——随插件一起打包。在光标处插入或覆盖选区，只产生一次撤销步骤，每个来源各自保留「常用」分组，并且保持打开以便连续插入多个字符。

### 📊 Markdown 表格编辑器

插入 / 删除行列、移动行列、列左中右对齐、升序或降序排序、删除重复行、转置表格、重排格式（美化当前表格，或笔记中的每一个表格），以及把表格转换回分隔文本——外加**粘贴为表格**：把剪贴板里以制表符或逗号分隔的文本（直接从 Excel、Numbers 或 Google Sheets 复制的）变成对齐好的 Markdown 表格，还有**复制为 ▼**，可以导出成 TSV、CSV、JSON 或 Markdown 再回到电子表格里。

把光标放进表格里，功能区会自动切到**表格**选项卡；你另外选了哪个选项卡，它就停在你选的那儿。在**源码模式**下，回车移动到下一行（到末尾则新增一行），Tab / Shift+Tab 在单元格间移动，越过右边缘时新增一列。

### 📌 固定任意命令 —— 包括其他插件的命令

**「已固定」是工具栏里唯一由你自己安排的部分。** 它把工具栏变成你自己的启动器：从命令面板里挑任意命令（Obsidian 核心、其他社区插件、或本插件的），选一个图标，给它一个分组，拖动排序。如果来源插件被禁用，按钮只是变灰——你的固定项会保留。

五个内置选项卡覆盖了多数人常用的命令；而你真正离不开的那一两个命令，往往落在这套之外——所以与其让你重建五个选项卡去够到它，工具栏干脆给你第六个、完全属于你的，并且更新时永不覆盖。

### 👁️ 阅读、专注与大纲工具

**实时预览/源码**（在当前窗格的渲染视图与原始 Markdown 之间切换）、**显示空白字符**（空格显示点、制表符显示箭头、不换行空格 / 表意空格 / EN & EM 空格显示橙色标记）、**显示行号**、**可读行宽**、**导航窗格**（Obsidian 的大纲）、**放大 / 缩小 / 100%**、**向右 / 向下拆分**、**折叠 / 展开（全部）**、**专注模式**（收起两侧边栏）、**禅模式**（真正全屏）和**打字机模式**（光标行固定在编辑器中部并高亮，其余行淡化）。

### 📑 一键生成目录

**目录**会在光标所在段落之后写入当前笔记的大纲：一个加粗的 `**目录**` 标题，然后每个标题一行嵌套的 `- [[#标题|标题]]` 链接。代码块内或被引用进 Callout 的标题会被忽略。它是快照，不是实时字段——改完笔记请重新生成，并删掉旧的。

### 🧹 行与列表工具

**合并行**、**拆分行**（按选区中出现最多的标点拆开）、**反转行**——三者都不会跨越空行或代码块——以及**重复**（把光标所在行复制一份到它的下面，或把选区复制一份紧接其后——VS Code 的*复制选定内容*）。此外还有**排序列表**（逐层排序，保留子项与正文，有序列表重新编号）和**排序标题**（重排大纲，并把每个章节的正文一起搬走）。

**清理**把那些大家平时只能手动做的整理动作收进一个菜单：**删除行尾空格**、**合并连续空行**、**转换裸 URL**、**统一强调和加粗**和**统一项目符号样式**。

### 🎨 零配置，跟随主题

内置布局是固定的，在浅色与深色模式下都继承你当前使用的 Obsidian 主题，装上就像原生的一样，并且一直如此。唯一需要你安排的，是**已固定**选项卡。

这是刻意的取舍，不是缺失的功能。一个允许你重建每个按钮的工具栏，还得一并背上一套拖拽编辑器、一个图标浏览器、一种导入导出格式，以及一个装下这些的设置页——而工具栏的 bug 恰恰就出自这套机械结构：按钮拖不动、布局被更新重置、设置面板卡死。固定布局一样都没有。你得到的是装上就能用、并且一直好用的工具栏，而那些真正属于你的命令，出口就是**已固定**。

## 快速上手

1. 打开**设置 → Awesome Format Bar**，勾选你想要的位置：**顶部**、**跟随**、**固定**。
2. **功能区（顶部）**&#x6709;六个选项卡；最后一个**已固定**放你自己固定的命令。它为空时会显示一条添加提示；用编辑按钮来管理命令和分组。
3. **精简工具栏**（跟随 / 固定）只带固定的一部分命令，放不进可用宽度的按钮会收进 `⋯` 溢出菜单，这个菜单同时还按选项卡分组列出所有其他命令，以及你固定的命令。
4. 打开**已固定**的编辑按钮，可以添加命令、选择图标、新建分组…或重命名分组、拖动排序、把命令移动到其他分组、删除命令。设置里也保留了一个打开同一个管理器的备用入口。固定后的命令行为与命令面板中的对应命令一模一样。
5. 更爱用键盘？把**三个位置开关全部关掉**，工具栏就从界面里彻底消失——插件不在屏幕上留下任何东西，而 **144 条已注册命令**依然可用，你可以在**设置 → 快捷键**里给它们绑定自己的热键。换句话说：你可以只把它当成一个纯命令 / 快捷键包，一个按钮都不点。

## 常见问题

**这会把 Obsidian 变成所见即所得或富文本编辑器吗？**  
不会——这正是重点。它是叠在 Obsidian 自有编辑器之上的**工具栏**，你的文件仍然是纯 Markdown。

**现在用 Obsidian 还得先学 Markdown 语法吗？**  
不用。加粗、标题、列表、链接、表格、Callout、代码块和公式全都是按钮。

**到底会往我的笔记里写什么？**  
标准 Markdown 和 Obsidian 风味 Markdown。只有在 Markdown 没有语法的地方——下划线、上标、下标、段落对齐、文字与高亮颜色、字体与字号——插件才会写入少量标准行内 HTML 标签，Obsidian 原生即可渲染。

**我还能继续用快捷键吗？**  
能。159 条命令中有 144 条出现在命令面板里，可以绑定到任意热键。

**我是键盘党——能把工具栏完全藏起来吗？**  
能，而且这样做什么都不会丢。在**设置 → Awesome Format Bar**里把三处位置（**顶部 / 跟随 / 固定**）全部关掉，插件在屏幕上零痕迹：没有功能区、没有浮动栏、没有底栏。**144 条已注册命令**依然全部可跑，从命令面板走，或者从你在**设置 → 快捷键**里指定的热键走——包括那些 Obsidian 没有内置快捷键的命令，比如字体颜色、高亮颜色、更改大小写、Callout、表格排序和行处理工具。把它当成一个随时可开的纯键盘层就行，鼠标慢的时候再想起来。

**我能给其他插件的命令加按钮吗？**  
能——就是**已固定**选项卡。从命令面板固定任意命令并选一个图标。如果来源插件被禁用，按钮变灰，固定项保留。

**表情选择器需要联网吗？**  
不需要。约 2,150 条表情、颜文字与符号全部随插件打包。

**插件会用到 AI，或以任何方式联网回传吗？**  
不会。代码里没有任何 AI 功能、没有 API key、没有网络请求、没有分析统计，也没有遥测——插件只读写你本地的 `.md` 文件，别的什么都不做。表情库是随插件打包的，所以在飞机上也能用。

**在阅读视图里给表格排序会改动我的文件吗？**  
不会。阅读视图下点击表头排序只是显示层面的，绝不修改笔记。

**怎么让图片居中，或者改它的尺寸？**  
把光标放到图片自己所在的那一行。**居中**（开始 · 段落）即可让它居中——单独占一行的图片*就是*一个段落，所以并不需要单独的图片命令；**图片大小 ▼**（插入 · 图片）把宽度设为 100–600 像素，或者用**原始大小**还原文件本身的尺寸；宽度写在别名之后而不是覆盖它，所以 `![[logo.png|公司标志]]` 会变成 `![[logo.png|公司标志|300]]`。**所有图片 ▼**不论光标在笔记哪里，都一次性把同一宽度应用到每一张图片。**替代文本**写入替代文本并选中它，**题注**在下方写入一行题注并选中它，而**重置图片**把这两者都去掉。**转换语法**在 `![[a.png]]` 与 `![](a.png)` 之间来回切换。所有内容都以纯 Obsidian 语法写入，所以就算不装这个插件，笔记读起来也是一样的。

**想要干净屏幕时能把工具栏藏起来吗？**  
能——在设置里关掉任意位置，或者三个全关彻底隐藏（上面那条键盘问题里说明了关掉后还剩什么可用）。

**它可配置吗？**  
刻意做得很少——这正是重点。内置布局固定且跟随主题，所以看起来永远是原生的，永远不需要重新排列，也永远不会被更新重置。你真正想改的东西全在一处：**已固定**选项卡——在这里添加任意命令、挑图标、分分组、拖成你要的顺序。理由见*功能 → 零配置，跟随主题*。

## 开发

```shell
npm install        # 安装依赖
npm run build      # 类型检查 + 测试 + 生产构建
npm run deploy -- /path/to/vault   # 把 main.js、manifest.json、styles.css 复制进笔记库
```

发布物只有三个文件：`main.js`、`manifest.json`、`styles.css`。

## 发布

```shell
npm version patch                    # 递增 package.json、manifest.json、versions.json；提交并打 tag
git push origin main --follow-tags   # 推送提交与标签
```

`npm version` 要求工作区干净。标签不带 `v` 前缀——它必须等于 `manifest.json` 里的 `version`，否则发布工作流会拒绝。

推送标签会触发 `.github/workflows/release.yml`：构建插件，并创建一个附带 `main.js`、`manifest.json`、`styles.css` 的**草稿**发布。发布这个草稿，该版本就对外可用了。
