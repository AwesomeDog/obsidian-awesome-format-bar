## Зачем панель форматирования в Obsidian

Obsidian быстр, **если** вы уже владеете Markdown. Для всех остальных — студентов, авторов, пришедших из Word или Google Docs, команд, которые обучают новых пользователей, — синтаксис становится стеной.

- **Не нужно запоминать синтаксис.** Выделите текст, нажмите **Полужирный**. И всё.
- **Знакомые термины Word.** Вкладки Главная / Вставка / Вид / Таблица, «Очистить формат», «Изменить регистр», «Область навигации».
- **Узнайте, на что способен Obsidian.** Выноски, ссылки на блоки, внедрение, блоки формул и теги получили свои кнопки — многие пользователи никогда не находят эти возможности в синтаксисе.
- **Делайте то, что не умеет Markdown.** Подчеркивание, надстрочный и подстрочный символы, выравнивание абзацев, цвет текста и выделения, шрифт и его размер — всё это записывается аккуратным встроенным HTML.
- **Обычный текст навсегда.** Никакого закрытого формата, базы данных или привязки к производителю — ваши заметки остаются обычными файлами `.md`.
- **Автономно и приватно.** Никаких сетевых вызовов, учетных записей и телеметрии. Библиотека примерно из 2 150 эмодзи поставляется вместе с плагином.
- **Удобно и для клавиатуры.** Отключите все три положения панели — интерфейс исчезнет полностью, а все 105 команд, зарегистрированных в палитре, останутся доступными и их можно назначить на свои сочетания клавиш.

## Возможности

### 🧭 Три положения панели в любых сочетаниях

- **Лента (Вверху)** — полная панель с вкладками, закрепленная над редактором. *Включена по умолчанию.*
- **Плавающая** — компактная панель, которая следует за выделением, как панель выделения в Word или Google Docs.
- **Внизу** — компактная панель, закрепленная в нижней части редактора.

Каждое положение включается независимо, поэтому можно использовать только плавающую панель, только ленту или все три сразу.

### 🅰️ 115 команд форматирования в привычном порядке

Полужирный, Курсив, Подчеркнутый, Зачеркнутый, Встроенный код, Формула в тексте, Выделение (с выбором цвета), Цвет шрифта, **Шрифт**, **Размер шрифта**, Очистить формат, Изменить регистр, Заголовок 1–6, маркированный / нумерованный список и список задач, Цитата, отступы, Горизонтальная линия, Отменить / Повторить, Найти и заменить, выравнивание абзацев — всё сгруппировано именно там, где этого ждет пользователь Word.

### 💬 Выбор выноски — все 12 типов выносок Obsidian

Одна кнопка **Выноска** открывает раскрывающийся список с `note`、`abstract`、`info`、`tip`、`success`、`question`、`warning`、`failure`、`danger`、`bug`、`example` и `quote`. Больше не нужно искать синтаксис `> [!tip]`.

### 😀 Автономный выбор эмодзи, каомодзи и символов (около 2 150 записей)

Панель **Эмодзи и символы** с поиском и тремя источниками — эмодзи, каомодзи и типографские символы — поставляется вместе с плагином. Символ вставляется в позицию курсора или поверх выделения за один шаг отмены, у каждого источника есть своя группа часто используемых, а панель остается открытой, чтобы вставить несколько символов подряд.

### 📊 Редактор таблиц Markdown

Вставка и удаление строк и столбцов, перемещение строк и столбцов, выравнивание столбцов по левому краю / по центру / по правому краю, сортировка строк, повторное форматирование таблиц — а также **Вставить как таблицу**, которая превращает текст из буфера обмена с разделителями-табуляциями или запятыми (прямо из Excel, Numbers или Google Sheets) в выровненную таблицу Markdown.

### 📌 Закрепите любую команду — в том числе из других плагинов

Вкладка **Закрепленные** превращает панель в вашу собственную панель запуска: выберите любую команду из палитры команд (ядро Obsidian, другой плагин сообщества или этот плагин), выберите значок, перетащите, чтобы изменить порядок. Если исходный плагин отключен, кнопка просто станет неактивной — закрепление сохранится.

### 👁️ Инструменты чтения, фокусировки и структуры

**Показывать пробелы** (точки для пробелов, стрелки для табуляций, оранжевые метки для неразрывных, идеографических, а также коротких и длинных пробелов), **Показывать номера строк**, **Удобная для чтения длина строки**, **Область навигации** (структура Obsidian), **Увеличить масштаб / Уменьшить масштаб / 100 %**, **Разделить вправо / Разделить вниз**, **Свернуть / Развернуть (все)**, **Режим фокуса** (свернуть обе боковые панели) и **Режим дзен** (настоящий полноэкранный режим).

### 📑 Оглавление в один щелчок

Команда **Оглавление** записывает структуру заметки после абзаца, в котором находится курсор: заголовок `**Оглавление**` полужирным шрифтом, затем по одной вложенной ссылке `- [[#Заголовок|Заголовок]]` на каждый заголовок. Заголовки внутри блоков кода и процитированные в выносках игнорируются. Это снимок, а не динамическое поле — после правки запустите команду снова и удалите прежнее оглавление.

### 🧹 Утилиты для строк и списков

**Объединить строки**, **Разделить строки** (по знаку препинания, который чаще всего встречается в выделении), **Обратить порядок строк** — ни одна из них не переходит через пустую строку или блок кода — а также **Сортировать список** (по уровням, с сохранением тела и дочерних элементов, с перенумерацией нумерованных пунктов) и **Сортировать заголовки** (изменяет порядок структуры и переносит тело каждого раздела вместе с заголовком).

### 🎨 Без настроек, с учетом темы

Фиксированная продуманная раскладка, которая наследует активную тему Obsidian в светлом и темном режимах. Единственное, что нужно упорядочить, — это вкладка «Закрепленные».

### Таблица

Доступна, когда курсор находится внутри таблицы: Удалить строки или столбцы, Вставить строки выше / ниже, Вставить столбцы слева / справа, Переместить строку вверх / вниз, Переместить столбец влево / вправо, Форматировать таблицы, Выровнять столбец по левому краю / по центру / по правому краю, Сортировать строки, **Преобразовать в текст**.
**Преобразовать в текст** записывает таблицу в виде строк с разделителями-табуляциями — точная противоположность команды **Преобразовать текст в таблицу** (Вставка · Блоки), которая превращает текст с разделителями-табуляциями или запятыми в выровненную таблицу Markdown. **Вставить как таблицу** делает то же самое с содержимым буфера обмена и работает в любом месте.

### Утилиты

**Объединить строки** собирает группу строк в одну; **Разделить строки** разбивает их по знаку препинания, который чаще всего встречается в выделении; **Обратить порядок строк** меняет порядок строк в каждой группе на обратный. Ни одна из трех команд не переходит через пустую строку или блок кода.
**Сортировать список** сортирует список по уровням — каждый пункт сохраняет своё тело и свои дочерние элементы, а нумерованные пункты перенумеровываются. **Сортировать заголовки** упорядочивает каждый уровень структуры заметки и переносит тело каждого раздела вместе с заголовком.

## Установка

Требуется Obsidian **1.13.7 или более поздней версии**.

**Из плагинов сообщества (рекомендуется)**
Настройки → **Плагины сообщества** → **Обзор** → найдите **«Awesome Format Bar»** → **Установить** → **Включить**.

**С помощью BRAT (бета-версии)**
Установите [BRAT](https://github.com/TfTHacker/obsidian42-brat), выполните команду *BRAT: Add a beta plugin* и вставьте URL этого репозитория.

**Вручную**
Скачайте файлы `main.js`、`manifest.json` и `styles.css` из выпуска в папку `<хранилище>/.obsidian/plugins/awesome-format-bar/`, затем включите плагин в разделе Настройки → Плагины сообщества.

## Начало работы

1. Откройте **Настройки → Awesome Format Bar** и включите нужные положения: **Вверху**、**Плавающая**、**Внизу**.
2. На **ленте (Вверху)** шесть вкладок; последняя, **Закрепленные**, содержит команды, которые вы закрепили сами. Пока она пуста, на ней отображается подсказка со ссылкой на настройки.
3. **Компактные панели** (Плавающая / Внизу) содержат фиксированный набор команд; всё, что не помещается, сворачивается в меню `⋯`.
4. Закрепляйте команды в разделе **Настройки → Закрепленные**: добавьте (выберите команду, затем значок), измените значок, перетащите, чтобы изменить порядок, или удалите. Закрепленные команды работают точно так же, как их аналоги в палитре команд.
5. Предпочитаете клавиатуру? Отключите **все три положения**, и панель полностью исчезнет из интерфейса — плагин не добавит на экран ничего, при этом все **105 команд, зарегистрированных в палитре**, продолжают работать и могут быть назначены на ваши сочетания клавиш в разделе **Настройки → Горячие клавиши**. Иными словами, плагин можно использовать как набор команд и горячих клавиш и ни разу не нажать кнопку мышью.

## Часто задаваемые вопросы

**Это превращает Obsidian в редактор WYSIWYG или в редактор форматированного текста?**
Нет — в этом и суть. Это **панель инструментов** поверх собственного редактора Obsidian. Ваши файлы остаются обычным Markdown.

**Теперь мне нужно учить синтаксис Markdown, чтобы пользоваться Obsidian?**
Нет. Полужирный, заголовки, списки, ссылки, таблицы, выноски, блоки кода и формулы — всё это кнопки.

**Что именно записывается в мои заметки?**
Стандартный Markdown и Markdown в варианте Obsidian. Лишь там, где в Markdown нет синтаксиса, — подчеркивание, надстрочный и подстрочный символы, выравнивание абзацев, цвет текста и выделения, шрифт и его размер — плагин добавляет небольшие стандартные встроенные теги HTML, которые Obsidian отображает сам.

**Можно ли продолжать пользоваться своими сочетаниями клавиш?**
Да. 105 из 115 команд отображаются в палитре команд, и на них можно назначить любое сочетание.

**Я работаю только с клавиатуры — можно ли полностью скрыть панель инструментов?**
Да, и вы ничего не потеряете. Отключите все три положения (**Вверху / Плавающая / Внизу**) в разделе **Настройки → Awesome Format Bar**, и плагин не оставит на экране никаких следов: ни ленты, ни плавающей панели, ни панели внизу. Все **105 команд, зарегистрированных в палитре**, по-прежнему работают — из палитры команд или по назначенному вами сочетанию в разделе **Настройки → Горячие клавиши**, включая команды, для которых в Obsidian нет встроенных сочетаний: цвет шрифта, цвет выделения, изменение регистра, выноски, сортировка строк и утилиты для строк. Считайте это дополнительным слоем для клавиатуры, который можно включить, когда мышь начинает казаться медленной.

**Можно ли добавить кнопки для команд из других плагинов?**
Да — для этого есть вкладка **Закрепленные**. Закрепите любую команду из палитры и выберите значок. Если плагин-владелец отключен, кнопка станет неактивной, а закрепление сохранится.

**Нужен ли панели эмодзи доступ к Интернету?**
Нет. Все примерно 2 150 эмодзи, каомодзи и символов поставляются вместе с плагином.

**Изменит ли сортировка таблицы в режиме чтения мой файл?**
Нет. Сортировка по щелчку заголовка в режиме чтения влияет только на отображение и никогда не изменяет заметку.

**Можно ли скрыть панель инструментов, когда нужен чистый экран?**
Да — отключите любое положение в настройках или все три, чтобы скрыть панель полностью (о том, что при этом продолжает работать, см. вопрос о клавиатуре выше).

**Можно ли это настроить?**
Настройка намеренно минимальна: раскладка фиксированная и учитывает тему, поэтому панель всегда выглядит «родной». А вкладка «Закрепленные» полностью в вашем распоряжении.

## Разработка

```shell
npm install        # установить зависимости
npm run dev        # сборка в режиме наблюдения
npm run build      # проверка типов + тесты + сборка для выпуска
npm run test       # запустить модульные тесты
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
npm run deploy -- /path/to/vault   # скопировать main.js, manifest.json, styles.css в хранилище
```

Выпуск состоит ровно из трех файлов: `main.js`、`manifest.json` и `styles.css`.

## Выпуск

```shell
npm version patch                    # обновляет package.json, manifest.json, versions.json; фиксирует изменения и создает тег
git push origin main --follow-tags   # отправляет коммит и тег
```

Для `npm version` требуется чистое рабочее дерево. Тег не содержит префикса `v` — он должен совпадать со значением `version` в `manifest.json`, иначе рабочий процесс выпуска его отклонит.

Отправка тега запускает `.github/workflows/release.yml`, который собирает плагин и открывает **черновик** выпуска с вложенными файлами `main.js`、`manifest.json` и `styles.css`. Опубликуйте черновик, чтобы версия стала доступной.
