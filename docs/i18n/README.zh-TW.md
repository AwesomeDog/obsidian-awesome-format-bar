## 為什麼需要一條格式列

如果你已經會寫 Markdown，Obsidian 就很快。但對其他人——學生、從 Word 或 Google Docs 轉過來的寫作者、正在帶新人的團隊——語法本身就是一堵牆。

- **不必背語法。** 選取文字，按**粗體**，就這樣。
- **你本來就認識的 Word 用語。** 常用 / 插入 / 檢視 / 表格選項卡、「清除所有格式」、「變更大小寫」、「導覽窗格」。
- **發掘 Obsidian 本來就有的能力。** 標註、區塊參照、內嵌、公式區塊、標籤全都有按鈕——很多使用者從來沒在語法裡發現過它們。
- **做 Markdown 做不到的事。** 底線、上標、下標、段落對齊、文字與醒目提示色彩、字型與字型大小，以乾淨的行內 HTML 寫入。
- **永遠是純文字。** 沒有專屬格式、沒有資料庫、沒有綁定——你的筆記仍然只是 `.md` 檔案。
- **離線且私密。** 不連網路、不要帳號、無遙測，約 2,150 筆的表情符號庫直接包在外掛裡。
- **也照顧鍵盤派。** 把三處工具列位置全部關掉，介面就徹底消失——105 筆已註冊到命令面板的指令依然可用，可以綁成你自己的快捷鍵。

## 功能

### 🧭 三處工具列位置，自由組合

- **功能區（頂端）** —— 固定在編輯器上方的完整分頁工具列。*預設。*
- **跟隨** —— 浮在目前選取範圍上方的精簡工具列，類似 Word 或 Google Docs 的選取工具列。 **跟隨列永遠不會蓋住你正在編輯的內容。**
- **底部** —— 固定在編輯器底部的精簡工具列。

每個位置各自獨立開關，你可以只用跟隨列、只用功能區，或者三處全開。

### 🅰️ 115 筆排版指令，版面配置你熟悉

粗體、斜體、底線、刪除線、行內程式碼、行內公式、醒目提示（可選色彩）、字型色彩、**字型**、**字型大小**、清除所有格式、變更大小寫、標題 1–6、項目符號 / 編號 / 工作清單、引文、縮排、分隔線、復原 / 重複、尋找及取代、段落對齊——全都依照 Word 使用者預期的位置分組。

### 💬 標註選擇器 —— 12 種類型全包

一個**標註**按鈕開啟下拉選單，內含 `note`、`abstract`、`info`、`tip`、`success`、`question`、`warning`、`failure`、`danger`、`bug`、`example`、`quote`。不必再查 `> [!tip]` 怎麼寫。

### 😀 離線表情符號、顏文字與符號選擇器（約 2,150 筆）

可搜尋的**表情符號與符號**面板，三個來源——表情符號、顏文字、排版符號——隨外掛一起打包。在游標處插入或覆蓋選取範圍，只產生一個復原步驟，每個來源各自保留「常用」分組，並且保持開啟以便連續插入多個字元。

### 📊 Markdown 表格編輯器

插入 / 刪除列欄、移動列欄、欄靠左 / 置中 / 靠右對齊、列排序、重排格式（美化表格）——外加**貼上為表格**：把剪貼簿中以 Tab 或逗號分隔的文字（直接從 Excel、Numbers 或 Google 試算表複製出來的）變成對齊好的 Markdown 表格。

### 📌 釘選任何指令 —— 包含其他外掛的指令

**已釘選**選項卡把工具列變成你自己的啟動器：從命令面板挑任何指令（Obsidian 核心、其他社群外掛、或本外掛的），選一個圖示，拖曳排序。如果來源外掛被停用，按鈕只是變灰——你的釘選會保留。

### 👁️ 閱讀、專注與大綱工具

**顯示空格**（空格顯示點、定位字元顯示箭頭、不換行空格 / 表意空格 / EN & EM 空格顯示橘色標記）、**顯示行號**、**可讀行寬**、**導覽窗格**（Obsidian 的大綱）、**放大 / 縮小 / 100%**、**向右 / 向下分割**、**摺疊 / 展開（全部）**、**專注模式**（收起兩側邊欄）、**禪模式**（真正的全螢幕）與**打字機模式**（游標行固定在編輯器中間並強調，其餘行淡化）。

### 📑 一鍵產生目錄

**目錄**會在游標所在段落之後寫入目前筆記的大綱：一個粗體的 `**目錄**` 標題，然後每個標題一列巢狀的 `- [[#標題|標題]]` 連結。程式碼圍欄內或被引用進標註裡的標題會被忽略。它是快照，不是即時欄位——改完筆記請重新執行，並刪掉舊的。

### 🧹 行與清單工具

**合併列**、**分割列**（依選取範圍中出現最多的標點符號切開）、**反轉行**——三者都不會跨越空白行或程式碼圍欄——以及**排序清單**（逐層排序，保留子項目與本文，編號項目重新編號）與**排序標題**（重排大綱，並把每個章節的本文一起帶著走）。

### 🎨 零設定，跟隨主題

固定、克制的版面配置，在淺色與深色模式下都繼承你目前使用的 Obsidian 主題。唯一需要你自己安排的，是「已釘選」選項卡。

## 完整命令參考

115 筆指令中有 105 筆註冊進了**命令面板**，可以為它們指定自己的快捷鍵。（下拉容器與表情符號與符號面板只出現在工具列。）

### 常用

- **剪貼簿** —— 貼上、剪下、複製、貼上為純文字
- **字型** —— 字型、字型大小、粗體、斜體、底線、刪除線、下標、上標、行內程式碼、行內公式、醒目提示、醒目提示色彩、字型色彩、清除所有格式、變更大小寫
- **段落** —— 項目符號 / 編號 / 工作清單、引文、減少 / 增加縮排、重新編號、段落排序、上移一列 / 下移一列、靠左對齊 / 置中 / 靠右對齊 / 左右對齊、分隔線
- **樣式** —— 標題 1–6、轉為本文
- **編輯** —— 復原、重複、尋找及取代

### 插入

內部連結、外部連結、內嵌、標籤、區塊參照、**標註 ▼**（註解標註、摘要標註、資訊標註、提示標註、成功標註、問題標註、警告標註、失敗標註、危險標註、缺陷標註、範例標註、引文標註）、程式碼區塊、公式區塊、表格、文字轉換為表格、註解、附加檔案、**表情符號與符號**、日期與時間、**目錄**、腳注。

### 檢視

- **顯示** —— 顯示空格、顯示行號、可讀行寬、導覽窗格（Obsidian 的大綱）
- **縮放** —— 放大、縮小、100%
- **視窗** —— 向右分割、向下分割
- **大綱** —— 摺疊、展開、全部摺疊、全部展開
- **沉浸式** —— 專注模式、禪模式、打字機模式

### 表格

游標位於表格內時可用：刪除列或欄、在上方 / 下方插入列、在左側 / 右側插入欄、列上移 / 列下移、欄左移 / 欄右移、格式化表格、欄靠左 / 置中 / 靠右對齊、列排序、**轉換為文字**。
**轉換為文字**把表格寫成以 Tab 分隔的列——正好是**文字轉換為表格**（插入 · 區塊）的反向操作，後者把以 Tab 或逗號分隔的文字變成對齊的 Markdown 表格。**貼上為表格**對剪貼簿做同樣的事，且在任何位置都能用。

### 公用工具

**合併列**把連續多列併成一列；**分割列**依選取範圍中出現最多的標點符號切開；**反轉行**把每組列的順序倒過來。三者都不會跨越空白行或程式碼圍欄。
**排序清單**逐層排序——每個項目保留自己的本文與子項目，編號項目輸出時重新編號。**排序標題**重排筆記大綱的每一層，並把每個章節的本文一起帶著走。
**貼上 URI 為連結**會用剪貼簿中的 URI 將選取文字包成連結。**智慧標點**和**中日韓間距**會正規化選取文字，**清理**則把常見的 Markdown 清理操作集中在一個選單中。

### 已釘選

你自己的指令，配你自己的圖示。參見[快速上手](#快速上手)。

## 安裝

需要 Obsidian **1.13.7 或更新版本**。

**從社群外掛安裝（建議）**
設定 → **社群外掛** → **瀏覽** → 搜尋 **「Awesome Format Bar」** → **安裝** → **啟用**。

**用 BRAT 安裝（測試版）**
安裝 [BRAT](https://github.com/TfTHacker/obsidian42-brat)，執行 *BRAT: Add a beta plugin*，貼上本儲存庫的網址。

**手動安裝**
從發布頁下載 `main.js`、`manifest.json`、`styles.css` 三個檔案，放進 `<保存庫>/.obsidian/plugins/awesome-format-bar/`，然後在設定 → 社群外掛中啟用。

## 快速上手

1. 開啟**設定 → Awesome Format Bar**，勾選你想要的位置：**頂端**、**跟隨**、**底部**。
2. **功能區（頂端）**有六個選項卡；最後一個**已釘選**放你自己釘選的指令。它空白時會顯示一條指回設定的提示。
3. **精簡工具列**（跟隨 / 底部）只帶固定的一部分指令，放不下的會收進 `⋯` 溢位選單。
4. 在**設定 → 已釘選**中釘選指令：新增（先選指令，再選圖示）、變更圖示、拖曳排序、刪除。釘選後的指令行為與命令面板中的完全一樣。
5. 更偏好鍵盤？把**三個位置開關全部關掉**，工具列就從介面中徹底消失——外掛在畫面上不留任何東西，而 **105 筆已註冊至命令面板的指令**依然可用，你可以在**設定 → 快捷鍵**中為它們綁定自己的快捷鍵。換句話說：你可以只把它當成一個純指令 / 快捷鍵包，一個按鈕都不點。

## 設定

| 分區 | 內容 |
| --- | --- |
| **工具列** | 頂端 / 跟隨 / 底部三處獨立開關 |
| **已釘選** | 你釘選的指令 —— 新增、變更圖示、排序、刪除 |
| **表格** | 按下 Enter 移至下一列；Tab / Shift+Tab 在儲存格間移動，右側邊緣按 Tab 新增一欄；以空格填滿儲存格；在閱讀模式中按一下標題排序（不會修改檔案） |

## 常見問題

**這會把 Obsidian 變成所見即所得或富文字編輯器嗎？**
不會——這正是重點。它是疊在 Obsidian 自有編輯器之上的**工具列**，你的檔案仍然是純 Markdown。

**現在用 Obsidian 還得先學 Markdown 語法嗎？**
不用。粗體、標題、清單、連結、表格、標註、程式碼區塊與公式全都是按鈕。

**到底會往我的筆記裡寫什麼？**
標準 Markdown 與 Obsidian 風味 Markdown。只有在 Markdown 沒有語法的地方——底線、上標、下標、段落對齊、文字與醒目提示色彩、字型與字型大小——外掛才會寫入少量標準行內 HTML 標籤，Obsidian 原生即可轉譯。

**我還能繼續用快捷鍵嗎？**
能。115 筆指令中有 105 筆出現在命令面板，可以綁定到任何快捷鍵。

**我是鍵盤派——能把工具列完全藏起來嗎？**
能，而且這樣做什麼都不會少。在**設定 → Awesome Format Bar** 中把三處位置（**頂端 / 跟隨 / 底部**）全部關掉，外掛在畫面上零痕跡：沒有功能區、沒有浮動列、沒有底列。**105 筆已註冊指令**依然全部能跑，從命令面板執行，或從你在**設定 → 快捷鍵**中指定的快捷鍵執行——包括那些 Obsidian 沒有內建快捷鍵的指令，例如字型色彩、醒目提示色彩、變更大小寫、標註、表格排序與列處理工具。把它當成一個隨時可開的純鍵盤層即可，等滑鼠慢下來時再想起它。

**我能為其他外掛的指令新增按鈕嗎？**
能——就是**已釘選**選項卡。從命令面板釘選任何指令並選一個圖示。如果來源外掛被停用，按鈕變灰，釘選保留。

**表情符號選擇器需要連上網路嗎？**
不需要。約 2,150 筆表情符號、顏文字與符號全部隨外掛打包。

**這個外掛會用到 AI，或以任何方式回傳資料嗎？**
不會。程式碼裡沒有任何 AI 功能、沒有 API 金鑰、沒有網路請求、沒有分析、也沒有遙測——外掛只讀寫你本機的 `.md` 檔案，除此之外什麼都不做。表情符號庫隨外掛打包，所以就算在飛機上也照樣能用。

**在閱讀模式中替表格排序會改動我的檔案嗎？**
不會。閱讀模式下按一下標題排序只是顯示層面，絕不修改筆記。

**想要乾淨畫面時能把工具列藏起來嗎？**
能——在設定中關掉任一位置，或三個全關徹底隱藏（關掉後還剩什麼可用，見上面那則鍵盤問題）。

**它可以設定嗎？**
刻意做得很少：版面配置固定且跟隨主題，所以看起來永遠像原生。「已釘選」選項卡交給你自己安排。

## 開發

```shell
npm install        # 安裝相依套件
npm run dev        # 監看模式建置
npm run build      # 型別檢查 + 測試 + 生產建置
npm run test       # 執行單元測試
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
npm run deploy -- /path/to/vault   # 把 main.js、manifest.json、styles.css 複製進保存庫
```

發布物只有三個檔案：`main.js`、`manifest.json`、`styles.css`。

## 發布

```shell
npm version patch                    # 遞增 package.json、manifest.json、versions.json；提交並建立標籤
git push origin main --follow-tags   # 推送提交與標籤
```

`npm version` 要求工作區乾淨。標籤不帶 `v` 前置詞——它必須等於 `manifest.json` 中的 `version`，否則發布工作流程會拒絕。

推送標籤會觸發 `.github/workflows/release.yml`：建置外掛，並建立一個附上 `main.js`、`manifest.json`、`styles.css` 的**草稿**發布。發布這份草稿，該版本就對外可用了。
