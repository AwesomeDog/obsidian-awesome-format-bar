**Awesome Format Bar**는 [Obsidian](https://obsidian.md)용 **서식 바（리본）플러그인**입니다. 노트 위에 Word처럼 익숙한 **편집기 도구 모음**을 겹쳐 띄워, 매일 쓰는 서식을 한 번의 클릭으로 처리합니다. 그래도 노트는 여전히 100% 순수 텍스트입니다.

도구 모음이 기록하는 모든 것은 **표준 Markdown**, **Obsidian 방식 Markdown**, 그리고 Markdown에 아예 문법이 없는 경우（밑줄, 위 첨자, 아래 첨자, 단락 맞춤, 글꼴 색, 글꼴, 글꼴 크기）에만 Obsidian이 기본으로 렌더링하는 소량의 **인라인 HTML**입니다.

*Obsidian **도구 모음 플러그인**, **서식 바**, **편집기 도구 모음**, **서식 있는 텍스트 / WYSIWYG 방식 편집 바**, **Markdown 서식 버튼**, **이모지 선택기**, **표 편집기**, 혹은 **Obsidian용 Word식 리본**을 찾고 계신가요? 바로 이 플러그인입니다.*

## 서식 바가 필요한 이유

이미 Markdown을 익힌 사람에게 Obsidian은 빠릅니다. 하지만 그렇지 않은 사람——학생, Word나 Google Docs에서 넘어온 필자, 새로운 필기자를 안내해야 하는 팀——에게는 그 문법 자체가 벽입니다.

- **외울 문법이 없습니다.** 텍스트를 선택하고 **굵게**를 누르면 끝입니다.
- **이미 아는 Word 용어.** 홈 / 삽입 / 보기 / 표 탭, "서식 지우기", "대/소문자 변경", "탐색 창".
- **Obsidian의 기능을 발견하게 됩니다.** 콜아웃, 블록 참조, 포함, 수식 블록, 태그에 모두 버튼이 있습니다——문법만 보면 많은 사용자가 끝내 찾지 못하는 기능들입니다.
- **Markdown으로 못 하는 것도 합니다.** 밑줄, 위 첨자, 아래 첨자, 단락 맞춤, 글자 색과 강조 표시 색, 글꼴과 글꼴 크기를 깔끔한 인라인 HTML로 기록합니다.
- **영원히 순수 텍스트.** 독자 형식도, 데이터베이스도, 종속도 없습니다——노트는 그저 `.md` 파일입니다.
- **오프라인이며 비공개.** 네트워크 요청도, 계정도, 원격 측정도 없습니다. 약 2,150개의 이모지 라이브러리가 플러그인 안에 들어 있습니다.
- **키보드 사용자도 배려합니다.** 도구 모음 위치 세 곳을 모두 끄면 인터페이스에서 완전히 사라집니다——명령 팔레트에 등록된 105개 명령은 그대로 남아 원하는 단축키에 연결할 수 있습니다.

## 기능

### 🧭 세 가지 도구 모음 위치, 자유로운 조합

- **리본（위쪽）** —— 편집기 위에 고정되는 탭이 있는 전체 도구 모음. *기본값.*
- **따라감** —— 현재 선택 영역 위에 떠 있는 간편 도구 모음. Word나 Google Docs의 선택 도구 모음과 같습니다.
- **아래쪽** —— 편집기 맨 아래에 고정되는 간편 도구 모음.

각 위치는 독립적으로 켜고 끌 수 있어, 따라감 바만, 리본만, 또는 세 곳 모두를 함께 쓸 수 있습니다.

### 🅰️ 익숙한 배치의 서식 명령 115개

굵게, 기울임꼴, 밑줄, 취소선, 인라인 코드, 인라인 수식, 강조 표시（색 지정 가능）, 글꼴 색, **글꼴**, **글꼴 크기**, 서식 지우기, 대/소문자 변경, 제목 1–6, 글머리 기호 / 번호 매기기 / 작업 목록, 인용, 들여쓰기, 가로줄, 실행 취소 / 다시 실행, 찾기 및 바꾸기, 단락 맞춤——Word 사용자가 기대하는 자리에 그대로 묶여 있습니다.

### 💬 콜아웃 선택기 —— 12종 모두

**콜아웃** 버튼 하나로 `note`, `abstract`, `info`, `tip`, `success`, `question`, `warning`, `failure`, `danger`, `bug`, `example`, `quote`가 담긴 드롭다운이 열립니다. 이제 `> [!tip]` 문법을 찾아볼 필요가 없습니다.

### 😀 오프라인 이모지·카오모지·기호 선택기（약 2,150개）

검색 가능한 **이모지 및 기호** 패널에 이모지, 카오모지, 인쇄 기호 세 가지 소스가 플러그인과 함께 들어 있습니다. 캐럿 위치에 넣거나 선택 영역을 덮어쓰며, 하나의 실행 취소 단계로 처리되고, 소스별로 '자주 사용하는 항목' 그룹을 유지하며, 여러 문자를 연속으로 넣을 수 있도록 열린 상태로 남습니다.

### 📊 Markdown 표 편집기

행 / 열 삽입과 삭제, 행과 열 이동, 열 왼쪽 / 가운데 / 오른쪽 맞춤, 행 정렬, 서식 다시 지정（보기 좋게 정렬）——여기에 **표로 붙여넣기**까지: 클립보드의 탭 또는 쉼표로 구분된 텍스트（Excel, Numbers, Google Sheets에서 그대로 복사한 것）를 정렬된 Markdown 표로 바꿔 줍니다.

### 📌 어떤 명령이든 고정 —— 다른 플러그인의 명령까지

**고정됨** 탭은 도구 모음을 나만의 실행기로 바꿔 줍니다. 명령 팔레트에서 아무 명령이나 고르고（Obsidian 코어, 다른 커뮤니티 플러그인, 또는 이 플러그인）아이콘을 고른 뒤 끌어 순서를 바꿉니다. 출처 플러그인이 비활성화되면 버튼이 흐리게 표시될 뿐——고정 항목은 그대로 남습니다.

### 👁️ 읽기, 집중, 개요 도구

**공백 표시**（스페이스는 점, 탭은 화살표, 줄 바꿈 없는 공백 / 표의 공간 / EN & EM 공백은 주황 표식）, **줄 번호 표시**, **읽기 편한 줄 길이**, **탐색 창**（Obsidian의 개요）, **확대 / 축소 / 100%**, **오른쪽으로 분할 / 아래로 분할**, **접기 / 펼치기（모두）**, **집중 모드**（양쪽 사이드바 접기）, **젠 모드**（진짜 전체 화면）.

### 📑 클릭 한 번으로 만드는 목차

**목차**는 캐럿이 있는 단락 뒤에 현재 노트의 개요를 적어 줍니다. 굵게 표시된 `**목차**` 제목 아래, 제목마다 들여쓴 `- [[#제목|제목]]` 링크가 한 줄씩 들어갑니다. 코드 블록 안에 있거나 콜아웃에 인용된 제목은 무시됩니다. 실시간 필드가 아니라 스냅샷이므로, 노트를 고친 뒤에는 다시 실행하고 예전 목차는 지워 주세요.

### 🧹 줄과 목록 유틸리티

**줄 병합**, **줄 분할**（선택 영역에서 가장 많이 쓰인 문장부호를 기준으로 나눔）, **줄 순서 뒤집기**——셋 모두 빈 줄이나 코드 블록을 넘지 않습니다——그리고 **목록 정렬**（단계별로 정렬하며 자식 항목과 본문을 보존하고 번호 항목은 다시 번호를 매김）과 **제목 정렬**（개요 순서를 바꾸고 각 절의 본문까지 함께 옮김）.

### 🎨 구성 없이, 테마를 그대로

고정되고 절제된 레이아웃이 밝은 모드와 어두운 모드 모두에서 현재 Obsidian 테마를 따릅니다. 직접 꾸며야 하는 것은 '고정됨' 탭 하나뿐입니다.

## 전체 명령 목록

115개 명령 중 105개가 **명령 팔레트**에 등록되어 있어 원하는 단축키를 지정할 수 있습니다.（드롭다운 컨테이너와 이모지 및 기호 패널은 도구 모음 전용입니다.）

### 홈

- **클립보드** —— 붙여넣기, 잘라내기, 복사, 텍스트로 붙여넣기
- **글꼴** —— 글꼴, 글꼴 크기, 굵게, 기울임꼴, 밑줄, 취소선, 아래 첨자, 위 첨자, 인라인 코드, 인라인 수식, 강조 표시, 강조 표시 색, 글꼴 색, 서식 지우기, 대/소문자 변경
- **단락** —— 글머리 기호 / 번호 매기기 / 작업 목록, 인용, 들여쓰기 줄이기 / 늘리기, 번호 다시 매기기, 단락 정렬, 한 줄 위로 / 아래로 이동, 왼쪽 / 가운데 / 오른쪽 / 양쪽 맞춤, 가로줄
- **스타일** —— 제목 1–6, 제목 해제
- **편집** —— 실행 취소, 다시 실행, 찾기 및 바꾸기

### 삽입

내부 링크, 외부 링크, 포함, 태그, 블록 참조, **콜아웃 ▼**（노트, 요약, 정보, 팁, 성공, 질문, 경고, 실패, 위험, 버그, 예시, 인용）, 코드 블록, 수식 블록, 표, 텍스트를 표로 변환, 메모, 파일 첨부, **이모지 및 기호**, 날짜 및 시간, **목차**, 각주.

### 보기

- **표시** —— 공백 표시, 줄 번호 표시, 읽기 편한 줄 길이, 탐색 창（Obsidian의 개요）
- **확대/축소** —— 확대, 축소, 100%
- **창** —— 오른쪽으로 분할, 아래로 분할
- **개요** —— 접기, 펼치기, 모두 접기, 모두 펼치기
- **몰입형** —— 집중 모드, 젠 모드

### 표

커서가 표 안에 있을 때 사용할 수 있습니다: 행 또는 열 삭제, 위에 / 아래에 행 삽입, 왼쪽에 / 오른쪽에 열 삽입, 행 위로 / 아래로 이동, 열 왼쪽으로 / 오른쪽으로 이동, 표 서식 지정, 열 왼쪽 / 가운데 / 오른쪽 맞춤, 행 정렬, **텍스트로 변환**.
**텍스트로 변환**은 표를 탭으로 구분된 여러 줄로 적어 줍니다——바로 **텍스트를 표로 변환**（삽입 탭）의 역연산이며, 후자는 탭이나 쉼표로 구분된 텍스트를 정렬된 Markdown 표로 만듭니다. **표로 붙여넣기**는 클립보드에 대해 같은 일을 하며 어디에서나 동작합니다.

### 유틸리티

**줄 병합**은 이어진 여러 줄을 한 줄로 합칩니다. **줄 분할**은 선택 영역에서 가장 많이 쓰인 문장부호를 기준으로 나눕니다. **줄 순서 뒤집기**는 각 묶음의 순서를 뒤집습니다. 셋 모두 빈 줄이나 코드 블록을 넘지 않습니다.
**목록 정렬**은 목록을 단계별로 정렬합니다——각 항목은 자기 본문과 자식 항목을 유지하고, 번호 항목은 다시 번호가 매겨집니다. **제목 정렬**은 노트 개요의 각 단계를 다시 배치하며 각 절의 본문까지 함께 옮깁니다.

### 고정됨

원하는 명령에 원하는 아이콘을 붙여 두는 곳입니다. [시작하기](#시작하기)를 참고하세요.

| 카오모지   | ~70       | 감정, 동물, 행동, 사람, 휴일               |
| 기호     | ~200      | 화살표, 수학, 인쇄, 통화, 원 안 문자, 장식 문자   |

모든 데이터가 플러그인 안에 들어 있어 선택기는 완전히 오프라인으로 동작합니다.

## 설치

Obsidian **1.13.7 이상**이 필요합니다.

**커뮤니티 플러그인에서 설치（권장）**
설정 → **커뮤니티 플러그인** → **찾아보기** → **“Awesome Format Bar”** 검색 → **설치** → **사용**.

**BRAT로 설치（베타 버전）**
[BRAT](https://github.com/TfTHacker/obsidian42-brat)를 설치하고 *BRAT: Add a beta plugin*을 실행한 뒤 이 저장소의 URL을 붙여넣으세요.

**직접 설치**
릴리스에서 `main.js`, `manifest.json`, `styles.css`를 내려받아 `<볼트>/.obsidian/plugins/awesome-format-bar/`에 넣고, 설정 → 커뮤니티 플러그인에서 플러그인을 사용하도록 설정하세요.

## 시작하기

1. **설정 → Awesome Format Bar**를 열고 원하는 위치를 켜세요: **위쪽**, **따라감**, **아래쪽**.
2. **리본（위쪽）**에는 탭이 여섯 개 있고, 마지막 **고정됨** 탭에 직접 고정한 명령이 담깁니다. 비어 있을 때는 설정으로 돌아가라는 안내가 표시됩니다.
3. **간편 도구 모음**（따라감 / 아래쪽）에는 정해진 일부 명령만 담기고, 들어가지 않는 항목은 `⋯` 오버플로 메뉴로 접힙니다.
4. **설정 → 고정됨**에서 명령을 고정합니다: 추가（명령을 고른 뒤 아이콘 선택）, 아이콘 변경, 끌어서 순서 변경, 삭제. 고정된 명령은 명령 팔레트에서와 똑같이 동작합니다.
5. 키보드가 더 편한가요? **위치 스위치 세 개를 모두 끄면** 도구 모음이 인터페이스에서 완전히 사라집니다——화면에 아무것도 남지 않지만, **명령 팔레트에 등록된 105개 명령**은 그대로 동작하며 **설정 → 단축키**에서 원하는 단축키로 묶을 수 있습니다. 다시 말해 버튼을 한 번도 누르지 않고 순수한 명령 / 단축키 팩으로만 쓸 수도 있습니다.

- 네트워크 접속도, 계정도, 원격 측정도 없습니다——모든 것이 로컬에서 실행됩니다.
- 릴리스 파일은 정확히 세 개입니다: `main.js`, `manifest.json`, `styles.css`.

## 자주 묻는 질문

**이 플러그인이 Obsidian을 WYSIWYG이나 서식 있는 텍스트 편집기로 바꾸나요?**
아니요——그게 핵심입니다. 이 플러그인은 Obsidian 자체 편집기 위에 얹힌 **도구 모음**일 뿐입니다. 파일은 여전히 순수 Markdown입니다.

**이제 Obsidian을 쓰려면 Markdown 문법을 배워야 하나요?**
아니요. 굵게, 제목, 목록, 링크, 표, 콜아웃, 코드 블록, 수식까지 모두 버튼입니다.

**정확히 무엇이 노트에 기록되나요?**
표준 Markdown과 Obsidian 방식 Markdown입니다. Markdown에 문법이 없는 경우——밑줄, 위 첨자, 아래 첨자, 단락 맞춤, 글자 색과 강조 표시 색, 글꼴과 글꼴 크기——에만 Obsidian이 기본으로 렌더링하는 소량의 표준 인라인 HTML 태그를 기록합니다.

**기존 단축키를 그대로 쓸 수 있나요?**
네. 115개 명령 중 105개가 명령 팔레트에 나타나며 어떤 단축키로도 지정할 수 있습니다.

**키보드만 쓰는 편인데, 도구 모음을 완전히 숨길 수 있나요?**
네, 그리고 숨겨도 잃는 것이 없습니다. **설정 → Awesome Format Bar**에서 세 위치（**위쪽 / 따라감 / 아래쪽**）를 모두 끄면 플러그인은 화면에 흔적을 전혀 남기지 않습니다: 리본도, 떠 있는 바도, 아래쪽 바도 없습니다. **명령 팔레트에 등록된 105개 명령**은 명령 팔레트에서든, **설정 → 단축키**에서 지정한 단축키로든 모두 그대로 실행됩니다——글꼴 색, 강조 표시 색, 대/소문자 변경, 콜아웃, 표 정렬, 줄 유틸리티처럼 Obsidian에 기본 단축키가 없는 명령까지 포함해서요. 마우스가 답답해질 때 언제든 켤 수 있는, 선택적인 키보드 전용 레이어로 생각하시면 됩니다.

**다른 플러그인 명령의 버튼을 추가할 수 있나요?**
네——**고정됨** 탭이 바로 그 용도입니다. 명령 팔레트에서 아무 명령이나 고정하고 아이콘을 고르세요. 출처 플러그인이 비활성화되면 버튼이 흐리게 표시되고 고정 항목은 유지됩니다.

**이모지 선택기에 인터넷 연결이 필요한가요?**
아니요. 약 2,150개의 이모지, 카오모지, 기호가 모두 플러그인에 포함되어 있습니다.

**읽기 모드에서 표를 정렬하면 파일이 바뀌나요?**
아니요. 읽기 모드에서 머리글을 클릭해 정렬하는 것은 표시만 바꾸며 노트를 절대 수정하지 않습니다.

**화면을 깔끔하게 쓰고 싶을 때 도구 모음을 숨길 수 있나요?**
네——설정에서 원하는 위치만 끄거나, 세 곳을 모두 꺼서 완전히 숨길 수 있습니다（그때 무엇이 남는지는 위의 키보드 관련 질문을 참고하세요）.

**설정할 수 있는 부분이 있나요?**
의도적으로 최소한만 남겼습니다: 레이아웃은 고정되어 있고 테마를 따르므로 언제나 기본처럼 보입니다. '고정됨' 탭만 직접 꾸미시면 됩니다.

## 개발

```shell
npm install        # 의존성 설치
npm run dev        # 감시 모드로 빌드
npm run build      # 타입 검사 + 테스트 + 프로덕션 빌드
npm run test       # 단위 테스트 실행
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
npm run deploy -- /path/to/vault   # main.js, manifest.json, styles.css를 볼트로 복사
```

릴리스 파일은 정확히 세 개입니다: `main.js`, `manifest.json`, `styles.css`.

## 릴리스

```shell
npm version patch                    # package.json, manifest.json, versions.json 버전 올리기; 커밋 및 태그 생성
git push origin main --follow-tags   # 커밋과 태그 푸시
```

`npm version`은 작업 트리가 깨끗한 상태여야 합니다. 태그에는 `v` 접두어가 없습니다——반드시 `manifest.json`의 `version`과 같아야 하며, 그렇지 않으면 릴리스 워크플로가 거부합니다.

태그를 푸시하면 `.github/workflows/release.yml`이 실행되어 플러그인을 빌드하고 `main.js`, `manifest.json`, `styles.css`가 첨부된 **초안** 릴리스를 만듭니다. 초안을 게시하면 해당 버전이 배포됩니다.
