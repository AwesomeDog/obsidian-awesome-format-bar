## なぜ書式バーが必要なのか

すでに Markdown が書ける人にとって、Obsidian は速いツールです。しかしそれ以外の人——学生、Word や Google Docs から移ってきた書き手、新しいメモ担当者を迎え入れるチーム——にとって、構文は壁そのものです。

- **覚える構文はありません。** テキストを選択して**太字**をクリックするだけ。
- **すでに知っている Word の用語。** ホーム / 挿入 / 表示 / テーブルのタブ、「書式のクリア」、「大文字/小文字の変更」、「ナビゲーションウィンドウ」。
- **Obsidian の機能を発見できる。** コールアウト、ブロック参照、埋め込み、数式ブロック、タグにもボタンがあります——構文の中では多くのユーザーが見つけられない機能です。
- **Markdown にできないこともできる。** 下線、上付き文字、下付き文字、段落の配置、文字色と蛍光ペンの色、フォントと文字サイズを、クリーンなインライン HTML として書き込みます。
- **ずっとプレーンテキスト。** 独自フォーマットなし、データベースなし、ロックインなし——ノートは相変わらず `.md` ファイルのままです。
- **オフラインかつプライベート。** 通信なし、アカウント不要、テレメトリーなし。約 2,150 件の絵文字ライブラリはプラグイン本体に同梱されています。
- **キーボード派にも優しい。** 3 か所のツールバー位置をすべてオフにすれば、UI は完全に消えます——コマンドパレットに登録された 105 個のコマンドはすべてそのまま使え、自分のホットキーに割り当てられます。

## 機能

### 🧭 3 か所のツールバー位置、自由に組み合わせ

- **上部（リボン）** —— エディターの上に固定される、タブ付きのフルツールバー。*既定で有効。*
- **追従** —— 現在の選択範囲の上に浮かぶコンパクトバー。Word や Google Docs の選択時ツールバーのようなものです。
- **下部（固定）** —— エディターの下端に固定されるコンパクトバー。

それぞれの位置は個別にオン / オフできるため、追従バーだけ、リボンだけ、あるいは 3 か所すべてを同時に使うこともできます。

### 🅰️ 使い慣れたレイアウトの 115 個の書式コマンド

太字、斜体、下線、取り消し線、インライン コード、インライン数式、蛍光ペン（色付き）、フォントの色、**フォント**、**文字サイズ**、書式のクリア、大文字/小文字の変更、見出し 1〜6、箇条書き / 段落番号 / チェックリスト、引用、インデント、区切り線、元に戻す / やり直し、検索と置換、段落の配置——Word ユーザーが期待するとおりの場所にグループ分けされています。

### 💬 コールアウトピッカー —— 12 種類すべてに対応

**コールアウト**ボタンを 1 つ押すだけで、`note`、`abstract`、`info`、`tip`、`success`、`question`、`warning`、`failure`、`danger`、`bug`、`example`、`quote` を含むドロップダウンが開きます。`> [!tip]` の構文を調べる必要はもうありません。

### 😀 オフラインの絵文字・顔文字・記号ピッカー（約 2,150 件）

検索可能な**絵文字と記号**パネルに、絵文字・顔文字・組版記号という 3 つのソースをプラグイン同梱で収録。キャレット位置への挿入や選択範囲の置換を 1 つの元に戻す操作として実行し、ソースごとに「よく使う項目」のグループを保持します。パネルは開いたままなので、続けて複数の文字を挿入できます。

### 📊 Markdown テーブルエディター

行と列の挿入 / 削除、行と列の移動、列の左 / 中央 / 右揃え、行の並べ替え、書式設定（整形）に加え、**テーブルとして貼り付け**を用意——Excel、Numbers、Google Sheets からそのままコピーしたタブ区切り / コンマ区切りのクリップボードテキストを、揃った Markdown テーブルに変換します。

### 📌 任意のコマンドをピン留め —— 他のプラグインのコマンドも

**ピン留め**タブは、ツールバーを自分専用のランチャーに変えます。コマンドパレットから任意のコマンド（Obsidian コア、他のコミュニティプラグイン、本プラグインのもの）を選び、アイコンを選び、ドラッグで並べ替え。配信元プラグインが無効になっても、ボタンがグレー表示になるだけで、ピン留めは保持されます。

### 👁️ 読書、集中、アウトラインのためのツール

**空白を表示**（スペースはドット、タブは矢印、ノーブレークスペース / 表意文字スペース / EN・EM スペースはオレンジのマーク）、**行番号を表示**、**読みやすい行の長さ**、**ナビゲーションウィンドウ**（Obsidian のアウトライン）、**拡大 / 縮小 / 100%**、**右に分割 / 下に分割**、**折りたたむ / 展開（すべて）**、**フォーカス モード**（両サイドバーを折りたたむ）、**禅モード**（真の全画面表示）、**タイプライターモード**（カーソル行を中央に固定して強調し、ほかを薄く表示）。

### 📑 ワンクリックで目次を生成

**目次**は、キャレットのある段落の直後にノートのアウトラインを書き出します。太字の `**目次**` 見出しに続けて、各見出しを入れ子の `- [[#見出し|見出し]]` リンクとして 1 行ずつ並べます。コードブロック内やコールアウトに引用された見出しは無視されます。これはライブなフィールドではなくスナップショットなので、編集後は再実行して古い目次を削除してください。

### 🧹 行とリストのユーティリティ

**行の結合**、**行の分割**（選択範囲で最も多く使われている句読点で分割）、**行を逆順に**——いずれも空行やコードブロックをまたぎません——に加え、**リストを並べ替え**（階層ごとに並べ替え、子項目と本文を保持し、段落番号は振り直し）と**見出しを並べ替え**（アウトラインを並べ替え、各セクションの本文も一緒に移動）を備えています。

### 🎨 設定ゼロ、テーマ追従

固定された、意見のあるレイアウトで、ライトモードとダークモードの両方でアクティブな Obsidian テーマを継承します。自分の手で並べ替える必要があるのは、ピン留めタブだけです。

## 全コマンド一覧

115 個のコマンドのうち 105 個が**コマンドパレット**に登録されているため、独自のキーボードショートカットを割り当てられます。（ドロップダウンコンテナーと絵文字と記号パネルはツールバー専用です。）

### ホーム

- **クリップボード** —— 貼り付け、切り取り、コピー、テキストとして貼り付け
- **フォント** —— フォント、文字サイズ、太字、斜体、下線、取り消し線、下付き文字、上付き文字、インライン コード、インライン数式、蛍光ペン、蛍光ペンの色、フォントの色、書式のクリア、大文字/小文字の変更
- **段落** —— 箇条書き / 段落番号 / チェックリスト、引用、インデントの減少 / インデントの増加、リストの再番号付け、段落の並べ替え、1 行上に移動 / 1 行下に移動、左揃え / 中央揃え / 右揃え / 両端揃え、区切り線
- **スタイル** —— 見出し 1〜6、見出しの解除
- **編集** —— 元に戻す、やり直し、検索と置換

### 挿入

内部リンク、外部リンク、埋め込み、タグ、ブロック参照、**コールアウト ▼**（ノート、概要、情報、ヒント、成功、質問、警告、失敗、危険、バグ、例、引用）、コード ブロック、数式ブロック、テーブル、テキストをテーブルに変換、コメント、ファイルの添付、**絵文字と記号**、日付と時刻、**目次**、脚注。

### 表示

- **表示する** —— 空白を表示、行番号を表示、読みやすい行の長さ、ナビゲーションウィンドウ（Obsidian のアウトライン）
- **ズーム** —— 拡大、縮小、100%
- **ウィンドウ** —— 右に分割、下に分割
- **アウトライン** —— 折りたたむ、展開、すべて折りたたむ、すべて展開
- **イマーシブ** —— フォーカス モード、禅モード、タイプライターモード

### テーブル

カーソルがテーブル内にあるときに利用できます：行または列の削除、上に行を挿入 / 下に行を挿入、左に列を挿入 / 右に列を挿入、行を上に移動 / 行を下に移動、列を左に移動 / 列を右に移動、テーブルの書式設定、列を左揃え / 列を中央揃え / 列を右揃え、行の並べ替え、**テキストに変換**。
**テキストに変換**は、テーブルをタブ区切りの行として書き出します——**テキストをテーブルに変換**（挿入 · ブロック）のちょうど逆の操作で、後者はタブ区切りまたはコンマ区切りのテキストを揃った Markdown テーブルにします。**テーブルとして貼り付け**はクリップボードに対して同じことを行い、どこでも使えます。

### ユーティリティ

**行の結合**は連続する行を 1 行にまとめ、**行の分割**は選択範囲で最も多く使われている句読点で行を分け、**行を逆順に**は行グループの順序を反転します。3 つとも空行やコードブロックをまたぎません。
**リストを並べ替え**は階層ごとに並べ替えます——各項目は自分の本文と子項目を保持し、段落番号付きの項目は振り直されます。**見出しを並べ替え**はノートのアウトラインの各階層を並べ替え、各セクションの本文も一緒に移動させます。

### ピン留め

自分のコマンドに、自分のアイコンを。詳しくは[使い方](#使い方)を参照してください。

### 絵文字と記号パネル

## インストール

Obsidian **1.13.7 以降**が必要です。

**コミュニティプラグインから（推奨）**
設定 → **コミュニティプラグイン** → **参照** → **「Awesome Format Bar」**を検索 → **インストール** → **有効化**。

**BRAT を使う（ベータ版）**
[BRAT](https://github.com/TfTHacker/obsidian42-brat) をインストールし、*BRAT: Add a beta plugin* を実行して、このリポジトリの URL を貼り付けます。

**手動インストール**
リリースページから `main.js`、`manifest.json`、`styles.css` をダウンロードし、`<Vault>/.obsidian/plugins/awesome-format-bar/` に置いたうえで、設定 → コミュニティプラグインから有効化してください。

## 使い方

1. **設定 → Awesome Format Bar** を開き、使いたい位置（**上部**、**追従**、**下部**）をオンにします。
2. **上部（リボン）**には 6 つのタブがあり、最後の**ピン留め**に自分でピン留めしたコマンドが入ります。空のうちは設定へ案内するヒントが表示されます。
3. **コンパクトバー**（追従 / 下部）には固定された一部のコマンドだけが並び、収まりきらない分は `⋯` のオーバーフローメニューに畳まれます。
4. **設定 → ピン留め**でコマンドをピン留めします：追加（コマンドを選び、次にアイコンを選ぶ）、アイコンの変更、ドラッグでの並べ替え、削除。ピン留めしたコマンドはコマンドパレットのものとまったく同じように動作します。
5. キーボード派ですか？**3 つの位置スイッチをすべてオフ**にすれば、ツールバーは UI から完全に消えます——プラグインは画面上に何も残しませんが、コマンドパレットに登録された **105 個**のコマンドは引き続き動作し、**設定 → ホットキー**で自分のホットキーに割り当てられます。言い換えれば、ボタンを一度もクリックせず、純粋なコマンド / ホットキーパックとして使うこともできます。

## よくある質問

**これを使うと Obsidian は WYSIWYG やリッチテキストエディターになるのですか？**
なりません——そこが要点です。これは Obsidian 自身のエディターの上に載る**ツールバー**であり、ファイルはプレーンな Markdown のままです。

**これで Obsidian を使うのに、やはり Markdown 構文を覚える必要がありますか？**
いいえ。太字、見出し、リスト、リンク、テーブル、コールアウト、コードブロック、数式はすべてボタンになっています。

**具体的にノートには何が書き込まれますか？**
標準 Markdown と Obsidian 風 Markdown です。Markdown に構文がない箇所——下線、上付き文字、下付き文字、段落の配置、文字色と蛍光ペンの色、フォントと文字サイズ——に限り、プラグインは小さな標準的なインライン HTML タグを出力します。Obsidian がネイティブに描画します。

**これまでどおりキーボードショートカットは使えますか？**
はい。115 個のコマンドのうち 105 個がコマンドパレットに表示され、任意のホットキーに割り当てられます。

**キーボード派なのですが、ツールバーを完全に隠せますか？**
はい、しかも隠しても何も失われません。**設定 → Awesome Format Bar** で 3 か所の位置（**上部 / 追従 / 下部**）をすべてオフにすれば、プラグインは画面上に痕跡を残しません。リボンも、フローティングバーも、下部バーもありません。コマンドパレットに登録された **105 個**のコマンドはすべて引き続き実行できます。コマンドパレットからでも、**設定 → ホットキー**で割り当てたホットキーからでも——フォントの色、蛍光ペンの色、大文字/小文字の変更、コールアウト、テーブルの並べ替え、行のユーティリティなど、Obsidian に標準ショートカットがないコマンドも含めて。マウスがもどかしくなったときにいつでもオンにできる、オプションのキーボード専用レイヤーだとお考えください。

**他のプラグインのコマンドにボタンを追加できますか？**
できます——それが**ピン留め**タブです。パレットから任意のコマンドをピン留めしてアイコンを選んでください。配信元プラグインが無効になっても、ボタンがグレー表示になるだけでピン留めは保持されます。

**絵文字ピッカーにインターネット接続は必要ですか？**
いいえ。約 2,150 件の絵文字・顔文字・記号はすべてプラグインに同梱されています。

**リーディングビューでテーブルを並べ替えるとファイルは変更されますか？**
いいえ。リーディングビューでのヘッダークリックによる並べ替えは表示のみで、ノートを変更することはありません。

**画面をすっきりさせたいとき、ツールバーを隠せますか？**
はい——設定で任意の位置をオフにしてください。3 つすべてオフにすれば完全に隠せます（オフにしても何が使えるかは、上のキーボードに関する質問を参照してください）。

**設定でカスタマイズできますか？**
意図的に最小限にしています。レイアウトは固定でテーマに追従するため、常にネイティブに見えます。自分の手で並べるのは、ピン留めタブだけです。

## 開発

```shell
npm install        # 依存関係をインストール
npm run dev        # 監視モードでビルド
npm run build      # 型チェック + テスト + 本番ビルド
npm run test       # ユニットテストを実行
npm run lint       # eslint
npm run typecheck  # tsc --noEmit
npm run deploy -- /path/to/vault   # main.js、manifest.json、styles.css を Vault にコピー
```

リリース物はちょうど 3 ファイルです：`main.js`、`manifest.json`、`styles.css`。

## リリース

```shell
npm version patch                    # package.json、manifest.json、versions.json を更新；コミットとタグを作成
git push origin main --follow-tags   # コミットとタグをプッシュ
```

`npm version` は作業ツリーがクリーンであることを要求します。タグに `v` 接頭辞は付けません——`manifest.json` の `version` と一致していないと、リリースワークフローに拒否されます。

タグをプッシュすると `.github/workflows/release.yml` が実行され、プラグインをビルドして `main.js`、`manifest.json`、`styles.css` を添付した**下書き**リリースを作成します。この下書きを公開すると、そのバージョンが利用可能になります。
